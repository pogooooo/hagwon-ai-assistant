# 학부모 정기 알림과 원본 문서 등록

디자인 변경은 main `1213d45`에 병합했다. 이 기능은 별도 `feat/parent-monthly-messages` 브랜치에서 작업했다.

## 관리자 사용

상단 봉투 또는 메뉴의 **학부모 알림**에서 설정한다.

1. 정기 리포트에서 수신 대상 반, 매월 날짜(1~28일), 한국 시간(08~20시)을 고른다. 선택한 달의 전월 기록을 사용한다.
2. 기본 문구를 바로 쓰거나 직접 고친다. **AI 문구 만들기**는 네이버 CLOVA에 일반 안내용 인사·마무리 문장만 요청한다. 이름·학원·월·학습 수치와 필수 항목은 서버가 넣는다. 학생 정보를 AI에 보내지 않는다.
3. 분석 월을 고르고 **리포트 미리보기 만들기**로 실제 대상·내용·학습 근거를 확인한다. 승인된 기록이 없으면 리포트를 꾸며내지 않는다.
4. **알림함에 전달 · 예약 확정**을 누르면 학부모 알림함으로 전달한다. **매월 자동 전달**을 켜 두면 설정한 날 이후 담당자가 접속하지 않아도 서버가 처리한다. 자동 전달을 끄면 검토 대기에 보관한다.

새 안내에서는 자유 문구를 작성하고 전체 반 또는 특정 반의 학부모를 선택한다. 전달 시각을 비우면 확정 즉시, 지정하면 해당 시각 이후 전달한다. 미리보기에서 취소할 수 있다. 학생별 이름은 자동 입력된다.

**현재 전달 채널은 로그인한 학부모의 서비스 내 알림함이다.** 문자·카카오톡·휴대폰 푸시를 발송했다고 표시하지 않는다. 네이버 SENS 문자에는 별도 서비스 ID, 등록 발신 번호와 인증이 필요하며 알림톡은 채널·승인 템플릿도 필요하다. 현재 프로젝트에 이 설정과 학부모 전화번호가 없어 외부 발송은 연결하지 않았다.

## 기록과 자동 처리

- `op_parent_policies`: 학원별 일정·대상 반·문구·자동 전달 여부와 설정 버전.
- `op_parent_messages`: 수신 학부모/학생, 작성·예약·전달·취소 상태, 본문, 근거 버전, 읽음 시각, 작성 당시 대상 반.
- `op_parent_runs`: 이미 처리한 학원·분석 월. 메시지에도 학원·학생·학부모·월별 고유 키가 있어 재시작·같은 요청 재전송으로 중복되지 않는다.
- 로컬 서버는 1분 주기로 처리한다. Cloudflare는 Durable Object의 지속 알람을 사용하므로 방문자가 없어도 처리된다. 정확히 해당 초에 도착하는 실시간 발송을 보장하지 않으며 일반적으로 다음 처리 주기에 전달한다.
- 보호자 연결, 학원, 현재 대상 반을 전달 시 다시 검사한다. 다른 학부모의 ID로 접근하면 내용을 반환하지 않는다.
- 결과는 기존 승인 학습 기록·승인 교재 분석에서 얻는다. 같은 학생의 항목별 집계를 별도로 표시하고 겹칠 수 있는 분석의 문항 수를 서로 합산하지 않는다. 전달 전 근거가 바뀌면 차단하고, 이미 전달한 자료가 철회·변경되면 이전 본문을 숨긴다.
- 검토 중인 리포트는 미리보기를 다시 만들어 새 문구·근거로 갱신할 수 있다. 이미 전달한 같은 월의 리포트는 자동 재발송하지 않는다.
- AI 문구 생성은 기존 네이버 호출 한도와 장애 처리 정책을 사용한다. 월별 대상마다 생성 API를 호출하지 않고 저장한 문구를 재사용한다. 키가 없어도 기본/직접 작성 문구와 정기 리포트는 동작한다.

AI 검증 중 자동 입력 변수 누락과 근거 없는 노력 평가 문장이 실제로 나왔다. 변수는 서버 소유로 바꾸고, 일반 안내·문의 목적을 벗어난 평가 문구는 기본 안내로 대체한다. 구조화된 필수 내용·수치 삽입은 모델의 자유 생성에 맡기지 않는다.

## RAG 원본 파일

기존 PDF·DOCX·HWPX·TXT·Markdown에 **XLSX·CSV·TSV·PPTX**를 추가했다. 업로드 시 빈 제목은 파일명으로 채운다. 파싱 결과를 검수·승인하면 기존 색인·검색·상담·인용으로 연결된다.

| 형식    | 처리                                                                                                                                                                                                                                                                      |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| XLSX    | 통합 문서의 실제 시트 연결 순서, 공유 문자열, 원본 행 번호, 표 헤더·셀을 보존한다. 빈 행으로 구분된 표는 분리한다. 숨긴 시트·행·열과 외부 링크는 읽지 않는다. 일반 시간/날짜/백분율 표시를 처리한다. 수식은 실행하지 않고 불확실 형식·수식·병합은 검수 대상으로 표시한다. |
| CSV/TSV | UTF-8/EUC-KR 텍스트에서 따옴표 안 구분자·줄바꿈을 셀로 유지한다. 열 개수 불일치·깨진 따옴표는 실패 처리한다. 첫 행을 헤더로 읽으며 수식을 실행하지 않는다.                                                                                                                |
| PPTX    | 프레젠테이션 연결 순서대로 공개 슬라이드의 텍스트·표와 슬라이드 번호를 보존한다. 발표자 메모·숨긴 슬라이드는 제외한다. 이미지/차트는 검수 대상으로 표시하고 복잡한 병합 표는 변환 안내 후 거부한다.                                                                       |

파일 크기·ZIP 압축 해제 제한과 개인정보 가림은 유지한다. 새 라이브러리를 추가하지 않았다. 표의 행·열·시트·슬라이드 정보는 기존 청크와 인용 위치에 들어간다. 구형 바이너리 HWP·DOC·XLS·PPT는 HWPX·DOCX·XLSX·PPTX 또는 PDF로 저장해야 한다. 이 작업은 파일 업로드 형식 확대이며 외부 폴더를 주기적으로 동기화하는 기능은 아니다.

## 검증과 재현

```powershell
npm run check
npm test
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/verify-service-browser.mjs --responsive --out .local/parent-message-browser
```

신규 검증은 승인 결과 → 리포트 → 미리보기 → 전달 → 학부모별 열람·읽음, 한국 시간 정기 처리, 늦은 승인, 중복 방지, 보호자 연결·반 변경, 근거 철회, 예약 취소, 설정 충돌과 AI 출력 검사를 포함한다. 원본 파일은 실제 ZIP·CSV 바이트를 파서에 넣고 Excel 등록 → 검색 → 최종 금액·올바른 행 인용도 확인한다.

검증 결과:

- 전체 자동 테스트 747개 통과. 신규 알림 10개, 원본 파일 7개를 추가했으며 기존 테스트를 삭제하지 않았다.
- 역할별 화면·로그인 294개(7개 폭), 접근성 42개, 상호작용 10개 통과. 기존 화면 39경로에 관리자·학부모 알림 경로가 추가됐다.
- 별도 합성 DB의 실제 웹에서 최종 네이버 호출 1회, 관리자 미리보기·확정, 학부모 열람·읽음과 다른 학부모 접근 거부를 확인했다. 검증 중 폐기한 방식의 호출을 포함하면 네이버 문구 생성 요청은 총 4회였다.
- lint·TypeScript·서식 검사와 Cloudflare 운영 묶음 생성·배포 dry-run 통과. 신규 기능은 작업 브랜치 상태이며 위 main에는 디자인 변경만 병합했다.
- 실제 학부모에게 문자나 카카오 메시지를 보내는 검증은 포함하지 않는다. Cloudflare의 신규 정기 알람은 코드·묶음 검증이며 배포 서버에서 한 달을 기다리는 장기 검증은 수행하지 않았다.
