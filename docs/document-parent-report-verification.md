# 문서 형식·학부모 자동 리포트 검증

작업 분리: 기능 기반 PR #10, 첨부 시안 디자인 PR #11을 순서대로 main에 병합한 뒤 fix/document-parent-report-verification 브랜치에서 검사·수정했다. 화면 스타일 수정은 이 브랜치에 포함하지 않는다.

## 재현한 오류와 수정

| 재현한 문제                                                             | 수정                                                                       | 검증                                                              |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 월간 미리보기를 먼저 만들면 예약 시각에도 초안으로 남음                 | 같은 학생·학부모·월의 기존 초안을 최신 승인 근거로 갱신해 예약 처리에 포함 | 수정 전 실패 → 수정 후 통과. 자동 전달을 나중에 켠 경우도 확인    |
| 한 학원의 삭제된 대상 반 설정이 다른 학원 처리와 예약 안내까지 중단시킴 | 학원별 처리를 분리하고 실패한 학원만 재시도. 오류는 서버 로그로 기록       | 수정 전 실패 → 수정 후 다른 학원 리포트와 예약 안내 전달 확인     |
| 초안 생성과 월간 처리 완료 기록 사이 저장 실패                          | 초안 생성·예약 전환·완료 기록을 한 트랜잭션으로 처리                       | 중간 저장 오류를 주입해 전체 롤백, 다음 실행의 한 번 전달 확인    |
| DOCX·HWPX에 읽지 않은 그림/개체가 있어도 정상 추출로 표시               | Office 검수 경고와 needs_review 표시, 파서 버전 갱신                       | 수정 전 실패 → 수정 후 통과. 그림·개체의 내용은 자동 OCR하지 않음 |

이미 전달했거나 명시적으로 취소한 리포트는 자동 재발송하지 않는다. 철회된 근거의 초안은 예약에 포함하지 않는다. 연도 경계에서도 한국 시간의 전월을 선택한다.

## 문서 검사 기준

등록 → 검수 대기에서 공개되지 않음 → 승인 → 검색 → 최종 답변의 반·금액·파일/개정/표 위치 → 원본 바이트 다운로드 → 새 개정판의 값·인용 갱신 → 철회 후 답변/출처 제외를 검사한다. 단순히 파서가 예외 없이 끝나는 것을 성공으로 세지 않는다.

합성 원본의 고정 값은 중2 내신반 310000원, 중1 기본반 250000원이다. 중2를 질문하면 250000원이 섞이지 않아야 한다. 수정 후에는 중2 330000원과 개정 2를 인용해야 한다. 정답이나 기존 테스트를 변경해서 통과시키지 않았다.

| 확장자                        | 자동 등록·검색·수정/철회 검증     | 외부 AI                                               |
| ----------------------------- | --------------------------------- | ----------------------------------------------------- |
| PDF (텍스트)                  | 통과                              | 불필요                                                |
| DOCX / HWPX                   | 각각 통과                         | 불필요, 내부 그림은 검수 경고                         |
| XLSX / CSV / TSV              | 각각 통과                         | 불필요                                                |
| PPTX                          | 통과                              | 불필요, 이미지/차트는 검수 경고                       |
| TXT                           | 통과, 기존 UTF-8/EUC-KR 검사 유지 | 불필요                                                |
| MD / MARKDOWN                 | 별칭 각각 통과                    | 불필요                                                |
| PNG / JPG / JPEG / WEBP / BMP | 확장자 각각 전 흐름 통과          | 자동 회귀에서는 판독 대역 사용, 아래 실제 호출과 구분 |
| 스캔 PDF                      | 로컬의 렌더링→판독 경로 확인      | 아래 실제 호출도 확인                                 |

위 표의 확장자별 수는 15건이다. PDF 스캔 경로와 미지원/Office 경고 검사 2건을 더해 신규 문서 테스트는 17개다. 신규 리포트 회귀는 7개이며 기존 755개와 합친 최종 자동 테스트 수는 779개다.

테스트 원본은 **fixtures**/document-formats에 있으며 실제 학생 정보를 포함하지 않는다. PDF와 이미지에는 같은 고정 수강료 표가 들어 있다. Word/한글/Excel/PowerPoint는 기본 표 구조를 가진 최소 원본이며, 모든 업체·버전·복잡한 배치의 문서를 대표하지 않는다.

## 실제 네이버 호출 결과

키를 저장소에 넣지 않고 별도 합성 DB에서 13회로 제한했다. 이미지/스캔 5입력 × 이중 판독 2회 = 10회, 리포트 안내 문구 3회다. HTTP/네이버 결과 코드는 모두 200/20000이었으며, 읽기 결과가 다르면 자동 승인하지 않았다.

| 실제 입력                           | 결과                                                                             |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| JPG, WEBP, BMP                      | 각각 판독 → 승인 → 중2 310000원 및 해당 파일 표 인용 통과                        |
| 스캔 PDF (로컬)                     | 판독 → 승인 → 같은 반·금액·페이지 인용 통과                                      |
| PNG                                 | 두 판독의 본문/표 배치가 달라 검수 상태로 보류. 자동 답변 성공으로 계산하지 않음 |
| 정중하게 / 따뜻하게 / 간결하게 문구 | 네이버 요청 후 필수 변수와 안전 검사에 맞는 최종 문구 3종 사용 가능              |

실제 그림 5건 중 4건의 자동 흐름 통과와 1건의 보류는 소규모 합성 표 검증 결과다. OCR 일반 정확도나 모든 PNG 파일의 문제로 해석하지 않는다. 보류 케이스를 삭제하거나 재시도 성공만 골라 보고하지 않았다. AI 문구에는 학생 이름·학습 기록을 보내지 않으며, 월간 수치와 근거는 승인 데이터에서 서버가 조립한다. 기본 문구로도 자동 리포트가 동작한다.

## Cloudflare 예약 알람 실동작

Wrangler 로컬 Cloudflare 실행 환경에서 실제 HTTP 로그인·학습 기록 등록/확정·전월 미리보기·자동 정책 저장을 수행했다. 테스트용 예약 API나 임의의 운영 데이터 수정 경로를 추가하지 않았다.

- Durable Object의 실제 setAlarm이 실행되어 미리 만든 전월 초안을 자동 전달했다.
- 학부모가 2문항 중 2문항 정답의 본문·근거를 열람하고 읽음 처리했다.
- 다른 학생의 학부모가 같은 리포트 URL을 열면 404였다.
- 운영 배포 서버에서 실제 학부모를 대상으로 발송한 검증과는 구분한다. 현재 채널은 서비스 내 알림함이며 SMS·카카오·휴대폰 푸시는 연결하지 않았다.

## 남은 제한

Cloudflare에는 PDF 페이지를 이미지로 바꾸는 네이티브 렌더러가 없어 스캔 PDF를 직접 판독하지 못한다. 일부 텍스트만 저장하는 경로는 차단하며 텍스트 PDF 또는 페이지 사진이 필요하다. 로컬의 성공을 Cloudflare 지원으로 표시하지 않는다.

구형 HWP/DOC/XLS/PPT, HEIC/TIFF/GIF/SVG는 미지원으로 명시적으로 거부한다. Office 내부의 사진·차트·수식, 저화질·손글씨·복잡한 병합 표는 자동 처리 범위를 넘어갈 수 있다. 문서 폴더/Drive 자동 동기화는 포함하지 않는다.
