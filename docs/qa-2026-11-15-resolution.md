## 일정 근거 선택 방식

운영 앱이 `selectEvidence`라는 서버 전용 선택 함수를 RAG 서비스에 제공한다. RAG의 질문 해석 결과를 이용하며 복합 질문은 각 하위 질문에 별도로 적용한다. 일정 질의의 검색·사실 조회에는 운영 DB의 정규 시간표와 확정 변경 일정만 제공한다. 기존 공지 DB는 읽기 호환 대상으로 포함한다. 보강 규정·환불·비용 등 일반 정책은 기존 문서 검색을 유지한다.

사용자가 요청 본문에서 출처나 권한을 지정할 수 없으며, 기존 학생·반·학원 접근 제어와 최종 인용 검사를 그대로 통과해야 한다. 데이터 변경 시 색인 버전 재검증과 이전 답변 인용 무효화가 적용된다. 공용 RAG 평가 엔진은 선택 함수를 주입하지 않으므로 기존 검색 정책을 유지한다.

검색은 기존 BM25를 유지한다. 이번 일정 불일치는 생성 모델이나 임베딩 성능 문제가 아니라 서로 다른 원본 사용 문제였다. CLOVA 생성기로 바꾸더라도 BM25에는 교체할 임베딩이 없으며, 별도 검색 성능 실험 없이 임베딩 모델을 추가하지 않았다.

## 함께 반영한 승인 숙제 분석

- 팀이 반영한 교재·배정·제출·승인 이력 구조를 읽어 분석한다. 신규 DB 마이그레이션이나 문제 인식 변경은 없다.
- 모든 문항 결과가 해당 교사 승인 버전과 일치할 때만 집계한다. 유형 미지정 문항도 전체 정답률 분모에 포함한다.
- 배정 당시 유형을 사용하며, 학생·반·월별로 명시적으로 공개한 분석만 RAG 근거가 된다.
- 정정·승인 철회·대상 변경 시 이전 분석을 무효화한다. 반 이동 후에도 관리자는 기존 공개를 철회할 수 있다.
- 같은 학생이 여러 반에 속하면 반별 근거를 구분한다. 같은 교재명의 학년·학기·판본도 필터에서 구분한다.

자동 테스트는 외부 AI 없이도 지켜야 하는 수치·출처·상태·권한을 검사한다. Gemini 1회 검증은 연결 확인이며 상담 정확도 측정이 아니다. 393/300문항 평가 결과나 목표 정확도를 이번 테스트 수로 대체하지 않는다.

핵심 회귀 질문은 ‘초등 수학반 11월 16일 수업 있나요?’, ‘초등 수학반 내일 수업 있나요?’(11/15 고정 시각), ‘초등 수학반 시간표’, ‘11월 25일 휴강 보강 언제예요?’, 권한 밖 중3반/학생B 질문, 보호자 A/B 각각 ‘우리 아이 요즘 뭐가 약해요?’, ‘주차 가능한가요?’이다. 값만 맞는지 보지 않고, 운영 시간표 인용 여부·달력 일치·학생별 출처 분리·타 사용자 접근 차단도 검사한다.

검증 도중 일반 RAG 경로의 컨텍스트 복제로 후속 질문·비교 답변 5개가 보류되는 회귀를 발견해 원래 컨텍스트 갱신을 보존하도록 수정했다. 일정 테이블이 아직 없는 문서 단독 테스트도 빈 자료로 처리하도록 보완했다. 기존 ‘근거 없는 질문은 관리자에게 보이지 않음’ 테스트는 이번 자동 수집 요구에 맞춰 기대 동작을 변경했으며, 타 보호자 차단 검사는 유지했다. 평가셋 정답이나 기존 테스트를 삭제하지 않았다.

## 가상 데이터 적용 방법과 남은 확인

```powershell
node --env-file-if-exists=.env.local scripts/prepare-qa-demo.ts .local/academy-operations.sqlite
```

가상 교습소 식별값을 검사하고, 기존 운영 함수의 권한·충돌·승인 검증을 거쳐 데이터만 넣는다. 정상 완료 후 재실행하면 동일 숙제·공개·상담 시간은 중복 생성하지 않는다. 11월 QA 시나리오용 날짜이며 실제 학원으로 자동 배포하거나 서버 시작 시 실행하지 않는다.

로컬 `.local/academy-operations.sqlite`는 실행 전 일관된 SQLite 백업을 생성했다. 적용 결과: 숙제 2건, 분석 공개 2건, 정규 반 4개, 상담 가능 시간 2개, 정원 9명. 중복 상담 정리 대상은 0건이었다. 데이터와 백업·키는 Git에 포함하지 않는다.

Cloudflare의 기존 DB와 배포 버전에는 이번 코드를 적용하지 않았다. 따라서 QA가 관찰한 원격 중복 상담·철회 문서·기존 데이터의 실제 건수 및 화면 수정 여부는 배포 후 확인해야 한다. 로컬 검증을 원격 검증으로 표기하지 않는다. CLOVA 전환은 키 준비 후 진행하며, 현재는 사용자가 지정한 Gemini 설정을 유지한다.
