# 네이버 서비스 화면 조사와 디자인 반영

2026-11-18. 운영 웹의 로그인·홈·상담과 공통 메뉴/카드를 수정했다.

| -------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| [네이버 웨일](https://whale.naver.com/ko/)   | 짙은 배경 위 파란 색 번짐, 큰 제목, 넓은 곡면과 입체적인 전면 요소 | 홈의 녹색·청록·파랑 다층 그라데이션, 원형 캐릭터 배경, 제목 크기와 대비 |

| [네이버웍스](https://naver.worksmobile.com/) | 여백이 넓은 제목/설명/버튼 배치, 제품별 기능 구분                  | 로그인 화면의 소개와 입력 영역 분리, 업무 카드와 메뉴 간격              |

데스크톱 브라우저로 직접 화면을 확인했다. 웨일의 실제 CSS에는 선형 그라데이션, 흰색으로 이어지는 투명도 마스크, 24~44px 곡면이 사용됐다. 그 구성 원리를 학원 서비스의 정보 밀도에 맞춰 적용했다. MYBOX는 접속 시 본문이 표시되지 않아 시각 참고에서 제외했다.

## 반영 내용

- 홈: 짙은 그라데이션 안에 밝은 질문 입력창, 기존 캐릭터와 말풍선, 서비스별 바로가기 카드.
- 로그인: 넓은 소개 영역과 독립된 입력 카드. 좁은 화면에서는 소개를 축약해 계정 입력을 우선 표시.
- 상담: 캐릭터 배경, 추천 질문, 답변과 인용, 입력창의 시각적 단계 구분.
- 공통: 제목 크기·행간, 카드 곡면·그림자, 메뉴 선택 상태, 하단 메뉴 정렬 조정.
- 접근성: 색 번짐 위 텍스트 대비, 키보드 포커스, 좁은 화면의 입력 크기, 움직임 감소 설정을 고려했다.

추가 이미지·웹폰트·런타임 라이브러리 없이 기존 캐릭터와 CSS로 구현했다. 상담·권한·데이터 처리 계약은 그대로 유지한다.

## 확인

- 역할 5종에 걸친 총 39개 경로를 화면 폭 1440/390/360px로 검사: 117개 페이지 응답·가로 넘침·스크립트 오류 검사 통과.
- 390px에서 역할별 39개 화면과 로그인 화면의 자동 접근성 검사 통과.
- 메뉴 열기/닫기·포커스 복귀·질문 전달·추천 질문 편집·로그아웃·민감 페이지 오프라인 처리 등 기존 브라우저 상호작용 8개 통과.
- 320/360/390/768/820/1024/1440px에서 로그인·홈·상담을 추가 확인. 데스크톱·모바일·태블릿 스크린샷 점검.
- 서비스 UI·운영 서버 기존 테스트 15개, lint·TypeScript·서식 검사 통과.

자동 접근성 검사는 전체 접근성을 보증하지 않는다. 실제 휴대폰 기기 검증과 생성 AI 성능 재평가는 이번 디자인 검증에 포함하지 않는다.
