# AXR 웹·모바일 디자인 개선

기준: 2b69110. 작업 브랜치: feat/service-design-refresh. 첨부한 ‘좋은 디자인 프롬프트 연구’의 위계·정돈감·실제 상태 검증 원칙을 적용했다.

공개 웹 3곳은 브라우저에서 직접 열어 화면을 확인했다. ‘2026년의 모든 디자인 추세’를 입증한 조사가 아니며, 현재 확인 가능한 서비스의 표현 방식을 학원 운영에 맞춰 선택했다. 영상·대형 사진·장식용 가짜 지표는 추가하지 않았다.

## 확인한 문제와 수정

| 확인한 문제                           | 영향                               | 변경                                                                                         |
| ------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------- |
| 제목·목록·입력창의 강조가 비슷함      | 지금 할 일과 읽을 기록 구분이 약함 | 관리자 업무 요약, 상담 입력, 실제 일정과 보조 자료를 분리                                    |
| 전체가 작은 글자와 얇은 선 위주       | 핵심 내용이 평평하게 보임          | 제목과 수치 대비, 여백, 흰 읽기 면과 낮은 채도의 바탕 사용                                   |
| 비어 있는 기록도 같은 큰 카드로 반복  | 불필요하게 긴 홈                   | 빈 기록을 짧은 상태 표시로 축약                                                              |
| 역할과 화면 크기에 따른 우선순위 차이 | 모바일에서 중요한 일정이 밀림      | 학부모·학생 모바일은 일정/숙제를 상담 입력보다 먼저 표시                                     |
| 한글 글꼴을 시스템 대체 글꼴에 의존   | 환경별 글자 폭·인상 변화           | 기존 설치 패키지의 Noto Sans KR 400/700을 자체 제공. Korean/Latin 4파일 약 1.08MiB, OFL 포함 |
| 누적된 스타일 덮어쓰기                | 화면별 일관성 점검이 어려움        | 공통 토큰, 탐색, 홈, 상담, 로그인, 기능별 요소, 반응형 순서로 스타일 재구성                  |

첨부한 모바일 시안에 맞춰 밝은 회색 바탕, 검정 탐색 영역, 라임색 행동 버튼과 둥근 카드를 사용한다. 기존 캐릭터를 유지하고, 실제 데이터는 제목·날짜·상태·근거로 구분한다. 모바일 하단 메뉴와 전체 메뉴, 상담 입력 시 하단 메뉴 숨김, 키보드 포커스 복귀를 유지했다.

변경 파일은 운영 화면의 application.ts, home.ts, service-design.css와 자체 제공 글꼴이다. 상담 엔진·권한·DB 스키마·AI 공급자는 변경하지 않았다. 새 실행 라이브러리를 추가하지 않았으며 디자인 검증에서 유료 AI를 호출하지 않았다. 글꼴 요청은 현재 서비스 안에서만 수행한다.

## 검증

- 기존 자동 테스트 755개 통과, 실패/삭제/비활성화 0개.
- 역할별 경로와 로그인 총 294화면: 320/360/390/768/820/1024/1440px의 응답·가로 넘침·스크립트 오류 검사 통과.
- 자동 접근성 검사 42화면, 메뉴·질문 전달·입력 편집·목록 이동·오프라인 개인정보 미저장 등 상호작용 10개 통과.
- 초기 화면 검사에서 모바일 메뉴의 글자 대비 4.44~4.45:1을 발견해 글자 색을 조정했다. 최종 42화면에서 자동 접근성 위반 0개.
- 한글/Latin 글꼴 4파일 로드 및 MIME 확인, 긴 한국어 질문 편집을 4개 폭에서 검사했다.
- 홈·상담·자료 화면에 CSS 글자 크기 2배를 적용한 별도 스트레스 검사: 390/1440px 6화면에서 가로 넘침 없음. 실제 운영 CSS를 변경한 것이 아니며 브라우저/실기기의 모든 확대 방식에 대한 보장은 아니다.
- lint·TypeScript·서식 검사와 Cloudflare 배포 묶음 dry-run 통과.

검증은 합성 DB와 브라우저 렌더링 기준이다. 실제 휴대폰 소프트 키보드·APK·사용자 선호도·실사용 성공률·생성 AI 정확도 검증을 대신하지 않는다. main 및 공개 Cloudflare 사이트는 이 작업에서 변경하지 않는다.

재현: npm run check, npm test, node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON scripts/verify-service-browser.mjs --responsive --out .local/design-refresh/qa-final.

## 첨부 시안 후속 적용

- 모바일 하단 메뉴를 검정 캡슐 형태로 띄우고 선택 아이콘을 라임색 원으로 표시했다. 글자 레이블과 접근성 이름은 유지했다.
- 웹은 검정 선택 메뉴, 흰 업무 요약, 둥근 입력과 버튼으로 같은 체계를 적용했다. 설치형 웹앱의 테마 색도 함께 변경했다.
- 로그인·상담 진입의 배경은 새로 생성한 가상의 공부 공간 장식 이미지다. 실제 학원 시설 사진이라는 주장은 하지 않는다. 기존 캐릭터는 유지한다. 최종 배포 자산은 WebP 약 154KB이며 원본 참조 화면의 사진을 복사하지 않았다.
- 디자인 변경 후 294화면·접근성 42화면·상호작용 10개와 lint/타입/서식 검사, Cloudflare dry-run을 확인했다. 기능 검증·수정은 디자인 PR 병합 후 별도 브랜치로 분리한다.
