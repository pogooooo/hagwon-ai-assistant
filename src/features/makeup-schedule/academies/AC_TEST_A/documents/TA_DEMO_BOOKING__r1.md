# 상담 시간과 예약 방법

## 상담 가능 시간

학부모 상담 가능 시간은 평일 14:00~18:00입니다. 상담 한 건은 30분입니다.

## 상담 예약 방법

상담 예약은 앱의 일정·예약 메뉴에서 희망 시간을 선택해 신청합니다. 담당 교사가 확인하면 예약이 확정됩니다.
