# 휴강·보강 안내 기준

[가상] 테스트 교습소의 휴강·보강 안내는 원장이 확정한 일정을 기준으로 합니다. 휴강에 따른 환불 여부와 금액은 상담봇이 판단하지 않으며 담당자가 확인하여 안내합니다.
