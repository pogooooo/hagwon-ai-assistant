기준 커밋은 `6cb6b56`입니다. 기존 평가 JSON/CSV와 v1 결과는 그대로 유지했습니다. 기존 186개 오답의 기록을 다시 집계한 결과, '결합' 48개 모두 v1에서 출처 검사와 하나 이상의 근거 접촉 검사를 통과했습니다. '보류' 21개와 '선택' 20개 역시 근거 접촉으로 기록됐습니다. v1의 접촉에는 검색 후보뿐 아니라 정형 사실, 생성 입력, 최종 인용도 들어가므로 해당 집계로 검색 성공이나 정확한 결합을 확정할 수 없습니다. 186개 전체의 원인별 재라벨링은 수행하지 않았습니다.

`slot-v2`는 슬롯마다 같은 답변 줄의 대상·값·단위 표현과 원본 출처·위치를 확인합니다. 한 근거 묶음 안의 출처는 모두 필요하며, 여러 묶음 중 하나가 충족되면 대체 가능합니다. 검색된 행과 실제 인용 위치는 별도로 확인합니다. 상태는 정확히 구분하며 부분 답변의 누락 필드, 확인 질문의 선택지, 담당자 연결 표시와 안전 위반을 검사합니다. 자동 판정 범위는 라벨링한 주장에 한정됩니다. 라벨에 없는 문장 전체의 사실 검증이나 393문항 v2 점수는 미측정입니다.
