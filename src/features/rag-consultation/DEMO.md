# DEMO — RAG 상담 직접 확인하기

모든 학원·원생·금액은 가상 데이터입니다. 아래 예시 20개(`answered` 14 — 그중 2개는 틀린 답인 실패 사례 · `abstained` 3 · `denied` 2 · `clarify` 1)는 손으로 쓴 것이 아니라 엔진을 실제로 실행한 출력입니다.

```bash
node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON src/features/rag-consultation/server/eval/demo.ts
```

- 생성 공급자는 `disabled`(키 없음)입니다. 아래 답변은 모두 정형 조회·문서 인용으로 만든 것이며 **생성 모델 출력이 아닙니다**.
- 실제 외부 생성 API 는 연결·검증하지 않았습니다.
- 예시 질문은 개발용 자료(academies-v1, academies-v2 의 개발 학원 `AC_HANGYEOL`)에서만 골랐습니다. 미공개 평가 학원 자료는 쓰지 않았습니다.

## 1. 직접 상담 테스트하는 방법(개발 전용 화면)

```bash
npm ci
```

```bash
npm run rag:dev
```

1. 브라우저에서 `http://127.0.0.1:8787/dev` 를 엽니다(127.0.0.1 에만 열림).
2. **계정**에서 가상 계정을 고릅니다. 표시 형식은 `계정 ID · 역할 · 학원 (자료)` 입니다.
   - 한결과학(PDF·스캔 원본 학원): `HK_VISITOR`(비회원), `HK_GUARDIAN_BAE`(자녀 둘), `HK_GUARDIAN_SHIN`, `HK_GUARDIAN_LIM`, `HK_STUDENT_DOHYUN`, `HK_STUDENT_SUA`, `HK_ADMIN`(관리자) 등
   - 가온수학·새솔영어·다온입시: `GA_GUARDIAN_KIM`, `SS_VISITOR`, `GA_ADMIN` 등
3. **문서 선택**: 그 계정 학원의 문서 목록이 나옵니다. 체크한 문서로만 검색·사실 조회를 합니다(비우면 권한 안의 전체). 권한이 없는 문서(다른 원생 리포트)는 체크해도 검색되지 않습니다.
4. 질문을 입력하고 **질문하기**를 누릅니다. 같은 대화 ID 로 이어서 물으면 후속 질문으로 처리됩니다(“대화 새로 시작”으로 초기화).
5. 결과:
   - **답변**: 상태(`answered`·`partial`·`abstained`·`clarify`·`denied`·`handoff`), 사유 코드, 빠진 항목, 인용(출처 ID·문서·쪽·절·표·행 위치)
   - **진단(개발 전용)**: 검색 전략, 생성 종류(꺼짐/모의/실제)와 호출 수, 단계별 시간(검색·정형 사실 조회·생성·해석/검증), 검색 호출별 순위·점수·신호, trace

진단 정보는 `/dev/api/*` 에서만 나옵니다. 운영 경로 `/api/rag/query` 응답에는 `answer·citations·requestId·status` 만 있습니다(테스트로 확인).

## 2. PDF 원본 → 검색 → 답변 흐름

1. 계정을 관리자(`HK_ADMIN`)로 바꿉니다.
2. **파일 업로드**에서 PDF(또는 DOCX·HWPX·TXT)를 고르고 **파싱 미리 보기**를 누르면 다음이 보입니다.
   - 정규화 Markdown(`<!-- page N -->` 쪽 표시, 표는 Markdown 표, 2단 편집은 왼쪽 단 → 오른쪽 단)
   - 쪽별 처리 방식(`text` / `ocr` + 신뢰도), 경고(OCR 저신뢰·개인정보 가림 등)
   - 청크 위치(쪽 · 절 · 표 · 행)
3. **색인**을 누르면 승인 상태로 색인되고 문서 목록에 `업로드 · pdf` 로 추가됩니다.
4. 같은 학원의 다른 계정(예: `HK_VISITOR`)으로 바꿔 그 문서 내용을 질문합니다. 인용 위치에 쪽 번호가 붙습니다.

시험용 파일: `server/__fixtures__/documents-v1/documents/`(표·2단·여러 쪽 표·스캔 good/poor/회전·DOCX·HWPX·EUC-KR TXT), `server/__fixtures__/academies-v2/AC_HANGYEOL/documents/*.pdf`.

같은 흐름은 자동 테스트로도 확인합니다: `server/__tests__/pdf-integration.test.ts`(PDF base64 업로드 → 색인 → 보호자 질문 → `1쪽` 인용, 다른 학원 계정에는 보이지 않음).

## 3. API 호출 예시

dev 서버의 `x-dev-user` 헤더는 모의 인증입니다(운영에서는 서버 세션에서 권한을 계산).

```bash
curl -s localhost:8787/api/rag/query -H 'content-type: application/json' -H 'x-dev-user: HK_VISITOR' -d '{"question":"초등 실험탐구반 일주일에 몇번이고 한번에 몇분 수업해요?"}'
```

```bash
curl -s localhost:8787/api/rag/query -H 'content-type: application/json' -H 'x-dev-user: HK_GUARDIAN_BAE' -d '{"question":"임도현 10월 정답률 알려주세요"}'
```

후속 질문(같은 `conversationId`):

```bash
curl -s localhost:8787/api/rag/query -H 'content-type: application/json' -H 'x-dev-user: HK_STUDENT_SUA' -d '{"question":"나 10월 리포트 취약 영역 뭐야?","conversationId":"c1"}'
```

```bash
curl -s localhost:8787/api/rag/query -H 'content-type: application/json' -H 'x-dev-user: HK_STUDENT_SUA' -d '{"question":"그거 9월이랑 같은거야?","conversationId":"c1"}'
```

관리자 PDF 색인(파일은 base64):

```bash
curl -s localhost:8787/api/rag/index -H 'content-type: application/json' -H 'x-dev-user: HK_ADMIN' -d "{\"approve\":true,\"file\":{\"fileName\":\"fee.pdf\",\"contentBase64\":\"$(base64 -w0 src/features/rag-consultation/server/__fixtures__/documents-v1/documents/PX_FEE_TABLE__r1.pdf)\"},\"document\":{\"academyId\":\"AC_HANGYEOL\",\"documentId\":\"DEMO_FEE\",\"revision\":1,\"documentType\":\"fee\",\"title\":\"데모 수강료표\",\"visibility\":\"academy_public\",\"validFrom\":\"2026-01-01T00:00:00+09:00\"}}"
```

개발 진단 API(개발 서버 전용):

```bash
curl -s localhost:8787/dev/api/ask -H 'content-type: application/json' -d '{"userId":"HK_VISITOR","question":"가을 과학탐구대회 상 받은 학생 몇명이에요?"}'
```
