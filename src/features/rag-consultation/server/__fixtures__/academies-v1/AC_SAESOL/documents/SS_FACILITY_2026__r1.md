# 시설 이용 안내

새솔영어학원은 새솔빌딩 2층 전체를 사용합니다. 원생 여러분이 쾌적하게 공부할 수 있도록 아래 이용 수칙을 지켜 주세요.

## 1. 시설 현황

| 시설 | 위치 | 규모·비치 물품 |
|---|---|---|
| 강의실 | 201호 ~ 203호 | 각 10석, 전자칠판 |
| 스피킹룸 | 204호 | 8석, 원어민 스피킹 수업 전용, 녹음 장비 |
| 자습실 | 205호 | 개인 칸막이 좌석 16석 |
| 새솔 리딩존(독서 공간) | 로비 옆 | 영어 원서 약 600권, 소파 좌석 6석 |
| 상담실 | 원장실 옆 | 보호자 상담·레벨테스트 결과 상담 |

## 2. 자습실 이용

- 자습실 운영 (평일 14:00~22:00, 토 10:00~14:00)
- 재원생은 수업 전후로 자유롭게 이용할 수 있으며, 좌석은 선착순입니다.
- 단어 재시험과 개별 보강도 자습실에서 진행되므로, 재시험 시간에는 일부 좌석이 지정석으로 운영됩니다.
- 자습실 안에서는 휴대전화를 무음으로 설정하고, 음식물 섭취는 금지합니다.
- 일요일·공휴일과 전 반 휴강일에는 자습실을 운영하지 않습니다.

## 3. 새솔 리딩존(독서 공간) 이용

- 리딩존 운영 (평일 14:00~20:00)
- 영어 원서는 레벨별 색 스티커로 분류되어 있으며, 담임 강사가 추천한 레벨부터 읽는 것을 권장합니다.
- **도서 대출**: 재원생 1인 2권, 1주일 (데스크에서 대출 기록 작성)
- 분실·훼손 시 같은 도서로 변상합니다.

## 4. 편의 시설

- 정수기와 개인 컵 보관함(로비)
- 분실물 보관함(데스크) — 2주 보관 후 폐기
- 학원 출입구와 복도에 CCTV 설치(녹화 영상은 30일 보관, 법령에 따른 요청 시에만 열람)

## 5. 와이파이(Wi-Fi)

- 학원 와이파이는 자습실과 리딩존에서 학습 목적으로만 이용할 수 있습니다.
- 와이파이 비밀번호는 보안을 위해 안내 자료에 기재하지 않습니다.

## 6. 안전 수칙

1. 비상구는 복도 끝(205호 옆)에 있으며, 소화기는 각 강의실 출입문 옆에 비치되어 있습니다.
2. 수업 중 몸이 아프면 담임 강사에게 알리고 상담실에서 쉬도록 합니다. 보호자께 바로 연락드립니다.
3. 엘리베이터와 계단에서 뛰지 않도록 지도해 주세요.
