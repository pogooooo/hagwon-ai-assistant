# 2026년 2학기 기말고사 대비 시간표

학부모님 안녕하세요. 중학교 2학기 기말고사 대비를 위해 **2026년 11월 23일(월)부터 12월 31일(목)까지** 아래 시간표를 적용합니다.
중2 내신반과 중3 내신·서술형반의 수업 시간이 늘어나며, 초등반과 중1 문법반은 기존 시간표와 같습니다.

## 1. 반별 수업 시간 (11월 23일부터)

| 반 | 정규 수업 | 원어민 스피킹 | 변경 여부 |
|---|---|---|---|
| 초5 리딩반 | 월·수 16:00~17:30 | 금 16:00~16:50 | 변경 없음 |
| 초6 리딩반 | 화·목 16:00~17:30 | 금 17:00~17:50 | 변경 없음 |
| 중1 문법반 | 화·목 19:00~20:40 | 월 19:00~19:50 | 변경 없음 |
| 중2 내신반 | 월·수·금 19:00~21:00, 토 13:00~15:00 | 목 19:00~19:50 | 정규 수업 연장 + 토요일 추가 |
| 중3 내신·서술형반 | 화·목 19:00~21:00, 토 10:00~12:00 | 토 12:10~13:00 | 정규 수업 연장 + 스피킹 시간 변경 |

## 2. 반별 원어민 스피킹 수업 (11월 23일부터, 주 1회)

- 초5 리딩반: 원어민 스피킹 금 16:00~16:50
- 초6 리딩반: 원어민 스피킹 금 17:00~17:50
- 중1 문법반: 원어민 스피킹 월 19:00~19:50
- 중2 내신반: 원어민 스피킹 목 19:00~19:50
- 중3 내신·서술형반: 원어민 스피킹 토 12:10~13:00

## 3. 변경 내용 요약

| 반 | 기존(11월 22일까지) | 변경(11월 23일부터) |
|---|---|---|
| 중2 내신반 | 평일 수업 100분, 토요일 수업 없음 | 평일 수업 120분, 토요일 내신 문제풀이 120분 추가 |
| 중3 내신·서술형반 | 평일·토요일 수업 100분, 스피킹은 정규 수업 직후 | 평일·토요일 수업 120분, 스피킹은 토요일 정규 수업 후 10분 휴식 뒤 시작 |

- 늘어나는 수업 시간에 대한 추가 수강료는 없습니다.
- 토요일 추가 수업일에는 셔틀버스를 운행하지 않습니다.
- 학교별 시험 일정에 따라 시험 직전 주에는 학교별 직전 보충이 추가될 수 있으며, 이 경우 담임 강사가 개별 문자로 안내합니다.

## 4. 유의 사항

1. 기말 대비 기간에도 단어 시험과 재시험 규정은 동일하게 적용됩니다.
2. 하원 셔틀 2회차 출발 시각 변경은 「셔틀버스 운행 안내」를 확인해 주세요.
3. 2027년 1월 시간표는 12월 중 별도로 안내드립니다.
