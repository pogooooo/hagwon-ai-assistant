# 2026년 하반기 수강료 안내

학부모님 안녕하세요. 새솔영어학원입니다.
2026년 9월부터 12월까지 적용되는 반별 수강료와 교재비, 셔틀버스 이용료, 납부 방법을 아래와 같이 안내드립니다.

- 적용 기간: 2026년 9월 1일 ~ 2026년 12월 31일
- 모든 금액은 원(KRW) 단위이며, 교육청에 신고한 교습비 기준입니다.

## 1. 반별 수강료 및 교재비

| 반 | 주 수업 횟수 | 1회 수업 시간 | 월 수강료 | 교재비 |
|---|---|---|---|---|
| 초5 리딩반 | 주 3회 (정규 2회 + 원어민 스피킹 1회) | 정규 90분 / 스피킹 50분 | 230,000원 | 18,000원 |
| 초6 리딩반 | 주 3회 (정규 2회 + 원어민 스피킹 1회) | 정규 90분 / 스피킹 50분 | 240,000원 | 18,000원 |
| 중1 문법반 | 주 3회 (정규 2회 + 원어민 스피킹 1회) | 정규 100분 / 스피킹 50분 | 290,000원 | 22,000원 |
| 중2 내신반 | 주 4회 (정규 3회 + 원어민 스피킹 1회) | 정규 100분 / 스피킹 50분 | 320,000원 | 25,000원 |
| 중3 내신·서술형반 | 주 4회 (정규 3회 + 원어민 스피킹 1회) | 정규 100분 / 스피킹 50분 | 340,000원 | 27,000원 |

- 월 수강료에는 원어민 스피킹 수업이 포함되어 있으며 별도 비용이 없습니다.
- 교재비는 하반기 주 교재 1세트 기준이며, 교재를 지급하는 달(9월 또는 등록 월)에 1회 청구합니다.
- 기말 대비 기간(11월 23일~)에 추가되는 수업 시간에 대한 별도 수강료는 받지 않습니다.

## 2. 형제·자매 할인

| 항목 | 내용 |
|---|---|
| 대상 | 형제·자매가 동시에 수강하는 경우 |
| 할인율 | 월 수강료의 10% |
| 적용 원생 | 월 수강료가 낮은 원생 1명 (같은 금액이면 동생) |
| 제외 항목 | 교재비, 셔틀버스 이용료 |

> 예) 중2 내신반(320,000원)과 초6 리딩반(240,000원)을 함께 수강하는 경우, 초6 리딩반 수강료에서 10%(24,000원)를 할인하여 216,000원을 납부합니다.

- 형제 할인은 등록 시 신청서에 형제 원생 이름을 기재하면 다음 납부분부터 자동 적용됩니다.
- 다른 할인(장기 수강 할인 등)과는 중복 적용되지 않습니다.

## 3. 셔틀버스 이용료 (희망자)

| 구분 | 월 이용료 |
|---|---|
| 왕복 이용 | 35,000원 |
| 편도 이용(등원 또는 하원) | 20,000원 |

- 노선과 정류장별 시각은 「셔틀버스 운행 안내」를 확인해 주세요.
- 월 중간에 이용을 시작하는 경우에도 이용료는 월 단위로 청구합니다.

## 4. 납부 방법

1. **납부 기간**: 매월 1일 ~ 5일 (첫 달은 등록일 기준)
2. **납부 수단**
   - 학원 데스크 카드 결제(일시불·할부 가능)
   - 원생별 가상계좌 이체 — 가상계좌 번호는 등록 시 보호자 휴대전화로 문자 안내
3. **영수증**: 카드 결제는 카드 영수증, 계좌이체는 요청 시 교습비 영수증 발급
4. 납부 기간이 지나면 알림장 앱과 문자로 한 차례 안내드립니다.

## 5. 참고 사항

- 레벨테스트는 무료입니다.
