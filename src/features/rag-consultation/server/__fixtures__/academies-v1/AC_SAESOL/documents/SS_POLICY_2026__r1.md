# 새솔영어학원 운영 규정

- 시행일: 2026년 3월 1일
- 이 규정은 새솔영어학원의 모든 반(초5 리딩반 ~ 중3 내신·서술형반)에 적용됩니다.

## 제1장 출결

| 구분 | 기준 |
|---|---|
| 정상 출석 | 수업 시작 시각 전 입실 |
| 지각 | 수업 시작 후 입실 (15분 이내) |
| 결석 처리 | 수업 시작 후 15분이 지나 입실하거나, 수업 시간의 절반 이상 불참 |
| 조퇴 | 담임 강사에게 사유를 알리고 보호자 확인 후 귀가 |

- 입실·퇴실 시 출결 단말기에 카드를 찍으면 보호자 휴대전화로 출결 알림 문자가 자동 발송됩니다.
- 결석이 예상되는 경우 수업 시작 전까지 학원으로 연락해 주세요.
- 한 달에 지각이 3회 이상이면 담임 강사가 보호자께 전화로 안내드립니다.

## 제2장 단어 시험 및 재시험

1. 단어 시험은 각 반 정규 수업 시작 후 첫 10분 동안 진행하며, 범위는 학원 알림장 앱으로 미리 안내합니다.
2. **통과 기준**: 정답률 80% 이상 (예: 20문항 중 16문항 이상)
3. **재시험**: 통과 기준에 미달한 원생은 같은 범위로 재시험을 봅니다.
   - 재시험 시간: 해당 수업 종료 후 자습실에서 20분 또는 다음 수업 시작 30분 전
   - 같은 범위의 재시험은 최대 2회까지 실시합니다.
   - 2회 재시험에도 통과하지 못하면 담임 강사가 보호자께 문자로 안내하고, 오답 단어 쓰기 과제를 제공합니다.
4. 월간 학습 분석 리포트의 단어 시험 정답률은 **첫 응시 결과**를 기준으로 하며, 재시험 결과는 반영하지 않습니다.
5. 결석으로 단어 시험을 보지 못한 경우 다음 수업 시작 30분 전에 응시합니다.

## 제3장 결석 시 보강

1. 질병·경조사·학교 공식 행사로 결석하는 경우 수업 시작 전까지 담임 강사에게 알리면 보강을 신청할 수 있습니다.
2. 보강은 담임 강사와 일정을 조율하여 같은 진도의 다른 반 수업 참여 또는 자습실 개별 보강으로 진행합니다.
3. 보강은 결석일로부터 2주 이내에 진행하는 것을 원칙으로 합니다.
4. 무단결석·개인 여행으로 인한 결석은 보강 대상이 아니며 수업 자료만 제공합니다.
5. 원어민 스피킹 수업 결석분은 개별 보강 대신 다음 스피킹 수업 시 과제 피드백으로 대체할 수 있습니다.
6. 학원 사정(강사 연수, 수능일 등)으로 인한 휴강은 학원이 보강 일정을 정하여 공지합니다(제5장 참고).

> 보강 일정은 담임 강사의 수업 일정과 강의실 사정에 따라 조율되며, 희망하는 날짜·시간으로 확정되지 않을 수 있습니다.

## 제4장 수강료 환불

수강료(교습비) 환불은 「학원의 설립·운영 및 과외교습에 관한 법률 시행령」의 교습비 반환 기준에 따릅니다.

| 반환 사유 발생 시점 | 반환 금액 |
|---|---|
| 수업 시작 전 | 이미 낸 수강료 전액 |
| 총 수업 시간의 1/3 경과 전 | 이미 낸 수강료의 2/3 |
| 총 수업 시간의 1/2 경과 전 | 이미 낸 수강료의 1/2 |
| 총 수업 시간의 1/2 경과 후 | 반환하지 않음 |

- 총 수업 시간은 해당 월(수강료 납부 기간)의 전체 수업 시간을 기준으로 합니다.
- 반환 사유가 발생한 날부터 5일 이내에 환불합니다.
- 교재비는 교재를 지급하기 전이면 전액 환불하며, 지급 후에는 환불하지 않습니다.
- 셔틀버스 이용료는 이용 시작 전이면 전액, 이용 시작 후에는 위 표와 같은 비율로 환불합니다.
- 환불 신청은 보호자가 학원 데스크 또는 원장실 전화로 해 주세요.

## 제5장 휴원 및 휴강

1. **정기 휴원**: 설·추석 연휴, 여름·겨울 정기 휴원(각 5일 이내). 정기 휴원 일정은 최소 2주 전에 공지합니다.
2. **학원 사정 휴강**: 강사 연수·수능일 등으로 휴강하는 경우 휴보강 공지에 보강 일정을 함께 안내합니다.
3. **천재지변·감염병 등**: 관할 교육지원청의 휴원 권고가 있으면 휴원하며, 휴원한 수업은 보강하거나 다음 달 수강료에서 일할 계산하여 차감합니다.
4. 정기 휴원 기간의 수강료는 월 수강료에 반영되어 있으며 별도로 차감하지 않습니다.

## 제6장 기타

- 원생과 보호자의 연락처 등 개인정보는 출결 알림과 학원 안내 목적으로만 사용하며, 다른 원생·보호자를 포함한 제3자에게 제공하지 않습니다.
- 학습 분석 리포트는 해당 원생의 보호자와 원생 본인에게만 제공합니다.
