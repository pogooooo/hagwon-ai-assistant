# 2027 겨울방학 원어민 영어 캠프 수강료(안)

> **내부 검토용 초안입니다. 원장 승인 전이며 학부모 안내에 사용하지 않습니다.**
> 일정·금액·정원은 강사 회의(11월 중) 후 변경될 수 있습니다.

## 1. 캠프 개요(안)

| 항목 | 내용(안) |
|---|---|
| 기간 | 2027년 1월 4일 ~ 1월 29일 (4주) |
| 대상 | 초5 ~ 중2 재원생 및 신규생 |
| 수업 | 원어민 스피킹·프레젠테이션 (주 4회, 1회 120분) |
| 담당 | 다니엘 브룩스(Daniel Brooks) 강사 외 1명 (채용 검토 중) |
| 정원 | 반별 8명, 2개 반 |

## 2. 캠프 수강료(안)

| 구분 | 금액(안) | 비고 |
|---|---|---|
| 캠프 수강료 (4주) | 480,000원 | 재원생 할인 검토 중 |
| 교재·활동비 | 45,000원 | 활동지·발표 자료 포함 |
| 간식비 | 미정 | 업체 견적 대기 |

## 3. 검토 사항

- 재원생 할인율(5% 또는 10%) 결정 필요
- 정규 수업과 시간 겹침 여부 확인(1월 정규 시간표 확정 후)
- 셔틀버스 운행 여부 미정
