# 새솔영어학원 학원 소개 및 이용 안내

> 본 안내문의 학원명·주소·연락처·인물은 모두 테스트용 가상 정보입니다.

## 1. 교육 방침

새솔영어학원은 "읽고, 쓰고, 말하는 영어"를 목표로 초등 고학년부터 중학생까지 단계별 영어 수업을 운영합니다.

1. **리딩 중심 기초 다지기** — 초등반은 영어 원서·지문 읽기와 어휘 학습을 중심으로 독해 기초를 만듭니다.
2. **문법과 내신의 연결** — 중등반은 학교 교과서 범위에 맞춘 문법·내신 대비 수업을 진행합니다.
3. **서술형 대비** — 중3 내신·서술형반은 조건 영작과 서술형 첨삭을 매주 진행합니다.
4. **원어민 스피킹 수업** — 모든 반이 주 1회 원어민 강사와 스피킹 수업을 합니다(반별 요일은 정규 시간표 참고).
5. **매월 학습 분석 리포트** — 숙제·단어 시험 결과를 단원별·유형별로 정리한 리포트를 매월 말 보호자께 발송합니다.

## 2. 수업 대상 및 개설 반

| 반 | 대상 | 수업 중점 |
|---|---|---|
| 초5 리딩반 | 초등학교 5학년 | 리딩·필수 어휘·기초 문법 |
| 초6 리딩반 | 초등학교 6학년 | 리딩·중학 대비 문법 |
| 중1 문법반 | 중학교 1학년 | 중1 핵심 문법·교과 어휘 |
| 중2 내신반 | 중학교 2학년 | 학교별 내신 대비·문법·독해 |
| 중3 내신·서술형반 | 중학교 3학년 | 내신 대비·서술형·조건 영작 |

- 반별 수강료는 「2026년 하반기 수강료 안내」, 수업 요일·시간은 「2026년 2학기 정규 시간표」를 확인해 주세요.

## 4. 운영 시간

| 구분 | 시간 |
|---|---|
| 평일(월~금) | 14:00~22:00 |
| 토요일 | 10:00~15:00 |

- 정기 휴원 및 임시 휴강은 학원 알림장 앱과 문자로 공지합니다.

## 5. 상담 안내

| 구분 | 상담 가능 시간 |
|---|---|
| 평일 | 14:00~19:00 |
| 토요일 | 10:00~13:00 |

- 방문 상담은 **전화 예약 후** 진행합니다(대표 전화 031-0000-8800).
- 평일 19:00 이후에는 수업이 집중되어 전화 연결이 어려울 수 있습니다. 문자로 남겨 주시면 다음 날 연락드립니다.
- 성적·학습 상담은 담임 강사가, 등록·수강료 상담은 원장이 진행합니다.

## 6. 무료 레벨테스트

처음 등록하는 원생은 반 배정을 위해 레벨테스트를 봅니다.

| 항목 | 내용 |
|---|---|
| 비용 | 무료 |
| 소요 시간 | 약 50분 (테스트 35분 + 결과 상담 15분) |
| 평가 영역 | 어휘·문법·독해·듣기 (중등은 서술형 1문항 추가) |
| 예약 가능 시간 | 평일 15:00 / 17:00, 토요일 10:30 |
| 준비물 | 필기구 (최근 학교 영어 시험지가 있으면 함께 지참) |

- 레벨테스트 결과는 당일 상담 시 안내하며, 결과지는 보호자 휴대전화로 문자 발송합니다.
- 레벨테스트 후 등록 여부는 자유롭게 결정하실 수 있습니다.

## 7. 등록 절차

1. 전화 또는 방문으로 레벨테스트 예약
2. 레벨테스트 및 결과 상담
3. 반 배정 및 잔여 좌석 확인(마감된 반은 대기 접수)
4. 등록 신청서 작성 및 첫 달 수강료·교재비 납부
5. 학원 알림장 앱 가입 안내
