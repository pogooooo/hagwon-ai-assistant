# 새솔영어학원 강사 소개

> 아래 인물은 모두 테스트용 가상 인물입니다.

## 1. 원장

**백승희 원장**
- 영어교육 전공, 초·중등 영어 지도 경력 15년
- 학원 운영 총괄, 신규 등록·수강료 상담, 레벨테스트 결과 상담 담당
- 매월 학습 분석 리포트 최종 확인 및 발행

## 2. 반별 담임

| 반 | 담임 | 원어민 스피킹 |
|---|---|---|

## 3. 강사 소개

### 한지수 강사 — 초등 리딩 담당
- 담당 반: 초5 리딩반, 초6 리딩반
- 영어영문학 전공, 초등 영어 리딩 지도 경력 8년
- 원서 읽기와 어휘 학습을 연결하는 '리딩 로그' 수업 운영
- 학원 독서 공간(새솔 리딩존) 도서 선정 담당

### 서동훈 강사 — 중등 문법·내신 담당
- 담당 반: 중1 문법반, 중2 내신반
- 영어교육 전공, 중등 문법·내신 지도 경력 10년
- 학교별 교과서·부교재 분석 자료 제작, 내신 대비 모의고사 출제

### 문가람 강사 — 중3 내신·서술형 담당
- 담당 반: 중3 내신·서술형반 (전 반 서술형 첨삭 병행)
- 영어영문학 전공, 서술형·영작 지도 경력 9년
- 조건 영작 첨삭과 서술형 감점 사례 분석 수업 운영

### 다니엘 브룩스(Daniel Brooks) 강사 — 원어민 스피킹 담당
- 담당: 전 반 원어민 스피킹 수업(반별 주 1회)
- 영어권 출신 원어민 강사, TESOL 자격 보유, 국내 초·중등 스피킹 지도 경력 6년
- 주제별 스피킹·발표 수업, 학기 말 스피킹 평가 진행
- 한국어 상담은 담임 강사가 함께 진행합니다.

## 4. 상담 안내

- 학습·성적 상담은 담임 강사, 등록·수강료 상담은 백승희 원장이 진행합니다.
- 강사 상담은 수업 시간을 피해 **전화 예약 후** 진행하며, 강사 개인 연락처는 안내하지 않습니다.
