# 다온입시학원 학원 소개

> 고등 국어·수학 내신과 수능을 함께 준비하는 소수정예 입시학원입니다.
> (가상 데이터: 실제 학원·주소·전화번호와 관련 없음)

## 1. 교육 방침

1. **내신과 수능의 연결** — 학교별 기출 분석으로 내신을 대비하고, 같은 단원을 수능형 문항으로 다시 다룹니다.
2. **소수정예 반 운영** — 반 정원은 12~14명 이내로 운영합니다.
3. **매주 확인하는 학습** — 주간 테스트와 숙제 결과를 단원·문항 유형별로 분석해 매월 말 「학습 분석 리포트」로 보호자와 학생에게 안내합니다.
4. **관리형 자습** — 수업 전후에 관리형 자습실(좌석 지정제)에서 자습할 수 있습니다.

## 2. 교육 대상 및 개설 과목

| 구분 | 대상 | 개설 반 |
|---|---|---|
| 수학 | 고1~고3 | 고1 수학 내신반, 고2 수학Ⅰ 내신반, 고3 수능 수학(미적분)반 |
| 국어 | 고1~고2 | 고1 국어 문학반, 고2 국어 독서반 |
| 특강 | 시기별 개설 | 시험 대비 특강(개설 시 별도 안내문 게시) |

※ 반별 수강료·시간표·모집 현황은 각 안내문을 확인해 주세요.

※ 주차 및 차량 등원 관련 사항은 「시설 안내」를 참고해 주세요.

## 4. 운영 시간 및 상담 시간

| 구분 | 평일(월~금) | 토요일 | 일요일·공휴일 |
|---|---|---|---|
| 학원 운영 | 14:00~23:00 | 10:00~18:00 | 휴무 |
| 전화·방문 상담 | 14:00~21:00 | 10:00~15:00 | 휴무 |

- 방문 상담은 **사전 예약제**입니다. 예약 없이 방문하시면 수업 시간에는 상담이 어려울 수 있습니다.
- 원장 상담(진로·입시)은 화·목요일 15:00~18:00에 예약을 받습니다.

## 5. 입학 상담 및 진단평가 절차

| 단계 | 내용 | 소요 시간 |
|---|---|---|
| ① 상담 예약 | 전화 또는 문자로 학생 학년·학교·희망 과목을 알려 주세요. | — |
| ② 진단평가 | 과목별 50분(수학·국어 각각), 학년별 기본 범위 | 약 1시간 |
| ③ 결과 상담 | 진단평가 결과와 학교 내신 일정을 바탕으로 반을 안내합니다. | 약 30분 |
| ④ 등록 | 수강 신청서 작성, 수강료 납부, 관리형 자습실 좌석 신청 | — |

- 진단평가는 무료입니다.
- 정원이 찬 반은 대기 등록을 받으며, 결원이 생기면 대기 순서대로 연락드립니다.
- 진단평가 결과지는 결과 상담 때 보호자에게 직접 설명드리며, 문자로 따로 보내지 않습니다.

## 6. 학습 분석 리포트 안내

- 재원생에게는 매월 말 과목별 「학습 분석 리포트」를 발송합니다(분석 기간: 해당 월 1일~말일).
- 리포트에는 대상 과제·주간 테스트 목록, 단원별·유형별 정답 현황, 자동 분석한 취약 영역, 담당 강사가 확인한 학습 방향이 담깁니다.
- 채점 오류가 확인되면 수정판을 다시 발송하며, 수정판에는 수정 사유를 적습니다.
