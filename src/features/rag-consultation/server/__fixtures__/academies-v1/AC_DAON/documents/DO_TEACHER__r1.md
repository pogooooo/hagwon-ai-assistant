# 다온입시학원 강사 소개

다온입시학원의 2026년 2학기 담당 강사를 소개합니다. (모든 강사 정보는 가상 데이터입니다.)

## 1. 수학과

### 한도윤 강사

| 항목 | 내용 |
|---|---|
| 담당 반 | 고1 수학 내신반, 12월 기말 대비 특강(고1 수학) |
| 강의 경력 | 고등 수학 강의 9년 |
| 수업 방식 | 개념 설명 후 학교별 기출 변형 문항으로 바로 확인, 서술형 첨삭 주 1회 |

### 정세린 강사

| 항목 | 내용 |
|---|---|
| 담당 반 | 고2 수학Ⅰ 내신반, 고3 수능 수학(미적분)반 |
| 강의 경력 | 고등 수학·수능 강의 12년 |
| 수업 방식 | 단원별 핵심 유형 정리, 수능형 4점 문항 실전 훈련 |

## 2. 국어과

### 오하람 강사

| 항목 | 내용 |
|---|---|
| 담당 반 | 고1 국어 문학반 |
| 강의 경력 | 고등 국어 강의 7년 |
| 수업 방식 | 갈래별 작품 감상법, 교과서 수록 작품 중심 내신 대비 |

### 윤재희 강사

| 항목 | 내용 |
|---|---|
| 담당 반 | 고2 국어 독서반 |
| 강의 경력 | 고등 국어(독서) 강의 8년 |
| 수업 방식 | 지문 구조도 그리기, 인문·사회·과학기술 지문 주제별 독해 훈련 |

## 3. 반별 담당 강사 한눈에 보기

| 반 | 담당 강사 |
|---|---|
| 고1 수학 내신반 | 한도윤 강사 |
| 고2 수학Ⅰ 내신반 | 정세린 강사 |
| 고3 수능 수학(미적분)반 | 정세린 강사 |
| 고1 국어 문학반 | 오하람 강사 |
| 고2 국어 독서반 | 윤재희 강사 |
| 12월 기말 대비 특강(고1 수학) | 한도윤 강사 |

※ 원장 임서경은 진로·입시 상담을 맡고 있으며, 정규반 수업은 담당하지 않습니다.
※ 강사와의 개별 상담은 관리 실장(차은비)을 통해 예약해 주세요.
