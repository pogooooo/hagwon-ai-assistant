# 12월 기말 대비 특강(고1 수학) 안내

2학기 기말고사를 앞둔 고1 학생을 위해 공통수학2 기말 범위(집합과 명제, 함수와 그래프)를 집중 정리하는 특강을 개설합니다.
정규반(고1 수학 내신반)과 별도로 신청·납부하는 과정입니다.

## 1. 특강 개요

| 항목 | 내용 |
|---|---|
| 특강명 | 12월 기말 대비 특강(고1 수학) |
| 대상 | 고1 (재원생·비재원생 모두 신청 가능) |
| 범위 | 집합과 명제, 함수와 그래프 (학교별 시험 범위 보충) |
| 기간 | 2026년 11월 26일(목) ~ 12월 19일(토) |
| 수업 일정 | 11월 26일(목)~12월 19일(토) 매주 목 19:00~21:30, 토 10:00~12:30 (총 8회) |
| 강의실 | 502호 |
| 담당 | 한도윤 강사 |

## 2. 수강료

| 구분 | 금액 | 비고 |
|---|---|---|
| 특강 수강료 | 280,000원 | 8회(총 20시간) 일괄 납부 |
| 교재비 | 12,000원 | 자체 제작 기말 대비 자료집 |

- 특강 수강료는 정규반 월 수강료와 별도입니다.
- 정규반 재원생이라도 특강 수강료 할인은 적용되지 않습니다.

## 3. 정원 및 신청

- 정원 12명(선착순), 2026년 11월 25일(수) 22:00 신청 마감
- 정원이 차면 마감일 전이라도 조기 마감합니다.
- 최소 개설 인원은 6명이며, 미달 시 마감 다음 날 오전에 개별 연락 후 전액 환불합니다.
- 신청 방법: 학원 방문 또는 전화(031-0000-3050) 신청 → 수강료 납부 시 신청 확정

## 4. 회차별 진행 계획

| 회차 | 날짜 | 내용 |
|---|---|---|
| 1 | 11월 26일(목) | 집합의 뜻과 연산 |
| 2 | 11월 28일(토) | 명제와 조건 |
| 3 | 12월 3일(목) | 필요조건·충분조건, 절대부등식 |
| 4 | 12월 5일(토) | 함수의 뜻과 그래프 |
| 5 | 12월 10일(목) | 합성함수와 역함수 |
| 6 | 12월 12일(토) | 유리함수와 무리함수 |
| 7 | 12월 17일(목) | 학교별 기출 실전 1 |
| 8 | 12월 19일(토) | 학교별 기출 실전 2 |

※ 학교별 시험 일정이 다르므로 7·8회차는 시험이 끝나지 않은 학교 학생 위주로 진행합니다.

## 5. 환불

특강 환불은 총 교습시간(20시간)을 기준으로 「운영 규정」 제4장 수강료 반환 기준을 적용합니다.
