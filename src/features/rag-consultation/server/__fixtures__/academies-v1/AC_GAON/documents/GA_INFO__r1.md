# 가온수학학원 학원 소개 및 이용 안내

> 중등 수학 전문 · 소수정예(반당 6~8명) · 숙제 기반 월간 학습 분석 리포트

가온수학학원은 중학교 1~3학년을 대상으로 수학만 가르치는 전문 학원입니다. 한 반을 6~8명으로 운영하여 강사가 모든 원생의 풀이 과정을 매 수업 직접 확인하고, 숙제 결과를 단원·문항 유형별로 분석해 다음 수업과 상담에 반영합니다.

## 1. 교육 방침

1. **소수정예 수업** — 반 정원을 6~8명으로 제한하고, 수업 중 개별 풀이 확인 시간을 따로 둡니다.
2. **개념 → 연습 → 오답 정리의 반복** — 새 개념을 배운 날에는 같은 개념의 기본·응용 문항을 숙제로 내고, 틀린 문제는 오답노트로 다시 풉니다.
3. **숙제 기반 학습 분석** — 매주 숙제 채점 결과를 단원별·유형별로 모아 매월 말 학습 분석 리포트로 보호자께 안내합니다.
4. **학교 진도와 내신 일정 존중** — 학교별 진도표와 시험 일정을 반영하여 시험 기간에는 내신 대비 시간표로 전환합니다.

## 2. 수강 대상 및 반 구성

| 반 | 대상 | 정원 | 수업 내용 |
|---|---|---|---|
| 중1 기본반 | 중학교 1학년 | 8명 | 교과 개념·연산 중심, 학교 진도 맞춤 |
| 중2 기본반 | 중학교 2학년 | 8명 | 교과 개념·기본 유형 중심 |
| 중2 심화반 | 중학교 2학년(레벨테스트 상위) | 6명 | 심화 유형·서술형 중심 |
| 중3 심화반 | 중학교 3학년(레벨테스트 상위) | 6명 | 중3 심화 + 고등 수학 선행(공통수학1) |
| 중3 내신집중반 | 중학교 3학년 | 8명 | 학교별 내신 기출·서술형 대비 |

※ 반별 수강료는 「수강료 안내」, 요일·시간은 「시간표」, 담당 강사는 「강사 소개」를 참고해 주세요.

## 5. 상담 안내

- 상담 가능 시간: 평일 14:00~17:00, 토요일 10:00~13:00
- 방문 상담은 전화로 예약해 주세요(1회 약 30분). 수업이 이어지는 평일 17:00 이후에는 전화 상담만 가능합니다.
- 재원생 보호자 정기 상담은 학기마다 1회(4월·10월) 담당 강사가 전화로 진행합니다.

## 6. 무료 레벨테스트

신규 원생은 반 배정을 위해 무료 레벨테스트를 봅니다.

| 단계 | 내용 | 소요 시간 |
|---|---|---|
| ① 예약 | 대표 전화 또는 문자로 희망 일시 예약 | — |
| ② 진단 평가 | 학년별 진단 평가(현재 학기 진도까지, 25문항) | 50분 |
| ③ 결과 상담 | 원장이 단원별 결과지를 보며 보호자·학생과 상담 | 20분 |
| ④ 반 배정 | 결과와 희망 시간대를 고려해 반 배정, 첫 수업 일정 안내 | — |

- 레벨테스트 비용은 없으며, 응시 후 등록 의무도 없습니다.
- 레벨테스트는 평일 15:00~17:00, 토요일 10:00~13:00에 진행합니다.
- 정원이 찬 반은 레벨테스트 후 대기 접수를 하며, 자리가 나는 순서대로 연락드립니다.

## 7. 질문 클리닉

| 요일 | 시간 | 장소 |
|---|---|---|
| 화·목 | 15:30~17:00 | 3층 클리닉실 |

- 재원생이면 누구나 예약 없이 이용할 수 있으며 추가 비용은 없습니다.
- 숙제·학교 과제·오답노트에서 막힌 문제를 가져오면 원장 또는 당번 강사가 1:1로 풀이를 봐 줍니다.
- 결석 보강이 질문 클리닉 시간에 잡히는 경우가 있으니 클리닉실 앞 게시판을 확인해 주세요.

## 8. 오답노트 운영

1. 숙제·테스트에서 틀린 문제는 오답노트에 **문제를 옮겨 적고, 틀린 이유를 한 줄로 쓴 뒤, 다시 풉니다.**
2. 담당 강사가 매주 첫 수업 시작 10분 동안 오답노트를 검사하고 확인 도장을 찍습니다.
3. 매월 마지막 주에는 그달 오답과 같은 유형의 문제로 「오답 재도전 테스트」(10문항)를 봅니다.
4. 오답노트 검사 결과는 월말 학습 분석 리포트의 강사 확인 학습 방향에 반영됩니다.

## 9. 학습 분석 리포트

- 매월 말, 그달 제출한 숙제를 기준으로 단원별·문항 유형별(계산·개념·응용·서술형) 정답 수를 정리한 리포트를 발행합니다.
- 리포트는 해당 원생의 보호자와 원생 본인만 열람할 수 있으며, 담당 강사가 확인한 학습 방향이 함께 실립니다.
- 채점 오류가 확인되면 리포트를 수정해 다시 게시하고 수정 사유를 함께 적습니다.
