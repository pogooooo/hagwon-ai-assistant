# 시설 안내

가온수학학원은 가상시 새빛구 학원로 21 건물의 3층 전체를 사용합니다. 엘리베이터에서 내리면 바로 앞이 데스크입니다.

## 1. 층별 배치(3층)

| 공간 | 위치 | 용도 |
|---|---|---|
| A강의실 | 데스크 왼쪽 | 중1 기본반·중2 기본반(8석) |
| B강의실 | 복도 안쪽 | 중2 심화반·중3 심화반(6석) |
| C강의실 | 복도 안쪽 | 중3 내신집중반(8석) |
| 자습실 | 복도 끝 | 개인 자습(16석) |
| 클리닉실 | 데스크 옆 | 질문 클리닉·보강 |
| 상담실 | 데스크 옆 | 보호자 상담·레벨테스트 |
| 휴게 공간 | 엘리베이터 앞 | 정수기, 간식 테이블 |

## 2. 자습실

- 자습실 운영: 평일 14:00~22:00, 토요일 10:00~18:00 (좌석 16석)
- 재원생이면 추가 비용 없이 이용할 수 있으며, 좌석은 지정하지 않고 도착한 순서대로 앉습니다.
- 시험 2주 전처럼 좌석이 부족한 기간에는 그날 수업이 있는 원생에게 먼저 자리를 드립니다.
- 자습실 안에서는 대화와 음식물 섭취를 하지 않습니다(뚜껑 있는 물병은 가능).
- 자습실 휴대폰 사용 기준은 「운영 규정」 제5조를 따릅니다.

## 3. 휴게 공간·정수기

- 정수기는 휴게 공간에 1대(냉·온수) 있으며 개인 컵 또는 비치된 종이컵을 이용합니다.
- 휴게 공간 테이블(6석)에서는 간단한 간식을 먹을 수 있습니다. 냄새가 강한 음식과 컵라면은 삼가 주세요.
- 화장실은 3층 복도 양쪽 끝에 있습니다(남녀 구분).

## 4. 주차

- 건물 지하 주차장 1시간 무료 (데스크에서 차량 번호 등록 시)
- 1시간이 넘으면 건물 관리사무소 기준 요금이 부과되며, 학원에서 추가 할인은 해 드리지 않습니다.
- 주차 공간이 넉넉하지 않으니 상담·레벨테스트로 방문하실 때는 가급적 대중교통을 이용해 주세요.

## 5. 와이파이 및 기타

- 와이파이 비밀번호는 안내 자료에 기재하지 않으며 데스크에서 개별 안내합니다.
- 건물 출입구와 학원 복도에 CCTV가 설치되어 있습니다(녹화 영상 30일 보관).
- 분실물은 데스크에서 2주 동안 보관합니다.
