# 가상 학원 3곳 RAG 테스트 자료 (academies-v1)

> **모든 학원·원생·보호자·강사·주소·전화번호·금액은 테스트용 가상 데이터**입니다. 실제 개인정보·실제 학원과 섞지 마세요.
> 형식 규칙은 [FORMAT.md](FORMAT.md), 무결성 검사는 `python3 -I validate_academies.py` (RAG 정확도 시험이 아님).

질문 90개의 기대 상태: answered 54 · abstained 15 · denied 12 · partial 3 · clarify 3 · handoff 3 (dev 60 / holdout 30).

학원마다 들어 있는 문서(실제 안내문·가정통신문·규정집 형식):

- 학원 소개(위치·운영/상담 시간·레벨테스트 등)
- 현행 수강료와 2027년 개정 수강료(효력 시작일이 다른 별도 문서)
- **미승인 초안**(겨울 특강·원어민 캠프·파이널 패키지): 검색되면 실패
- 정규 시간표와 변경 시간표(기말 대비 / 수능 이후)
- 강사 소개
- 운영 규정: 출결·보강 절차(횟수 한도 없음)·학원법 시행령 환불 기준·휴대폰 등
- 시설 안내(와이파이 비밀번호는 "기재하지 않음")
- 11월 모집 현황, 11~12월 휴보강 공지(수능일 휴강, 반별 휴강·보강)
- 원생별 월간 분석 리포트: 9·10월, 일부 11월(발행 전 조회 시험). 리포트에는 대상 숙제, 단원별·유형별·전체 정답, 취약 영역, 강사 확인 학습 방향, 작성·수정일이 있습니다.

## 학원별 특징과 함정

- **가온수학학원**
  - 형제(김서준 중3 심화 / 김서윤 중2 심화)를 둔 보호자 계정, 이도윤 10월 채점 수정(r1 → r2, 11-05 10:00)
  - 이도윤·김서윤의 같은 값(10월 사각형의 성질 11/14)
  - 박하은은 학습 방향 없음(생성 경로·장애 시 담당자 연결)
- **새솔영어학원**
  - 셔틀 2개 노선 운행표(1회차/2회차 열 혼동 함정)
  - 원어민 스피킹(반마다 정규 + 스피킹 시간표 2개)
  - 형제 할인, 단어 재시험 "최대 2회"(보강 횟수로 오인하면 실패)
  - **문서 안 지시문(프롬프트 인젝션)이 들어간 학부모 건의 게시판 답변 모음**
  - 윤채원 10월 채점 수정(취약 영역도 바뀜), 강시우는 학습 방향 없음
- **다온입시학원**
  - 송지안의 수학·국어 리포트 분리(과목 귀속 함정)
  - 12월 기말 특강(별도 수강료·정원·마감), 고3반 수능 후 종료
  - 주차 공간 없음(답할 수 있는 부정 사실), 류태윤 10월 채점 수정
  - 문건우는 학습 방향 없음

## 사용

- 회귀 테스트: `npm test` (`server/__tests__/academies-regression.test.ts`)
- 로컬 dev 서버: `npm run rag:dev` 후 `x-dev-user: GA_GUARDIAN_KIM` 처럼 `users.json` 의 계정 ID 를 헤더로 보냅니다.

## 중학생 표현 평가(`eval/`)

- `eval/middle-school-paraphrase.jsonl`: 가온·새솔 중학생/방문자 계정의 구어체 질문 100개(답할 수 있는 85 + 보류 15). 문서에 정답 문구가 실제로 있는지 스크립트로 확인했습니다.
- `also_valid_source_ids`: 작성자가 notes 에 "같은 문구가 다른 문서에도 있음"이라 적은 3문항의 대체 정답 문서.
- `eval/results/techniques.json`: 기술 조사 검색 기법(BM25·Kiwi·e5 임베딩·RRF·bge 재정렬·점수 보류) 구성별 문항 결과(검색 순위·점수·엔진 답변). 비교 방법과 해석은 기능 폴더의 `REPORT.md` 2장.

## 한계
