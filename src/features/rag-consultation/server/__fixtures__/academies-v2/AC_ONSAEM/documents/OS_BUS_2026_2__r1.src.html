  1. 정류장에서는 차량 도착 후 2분만 기다린 뒤 출발합니다. 늦을 경우 다음 회차를 이용하거나 보호자가 직접 등원시켜 주세요.
  2. 차량을 타지 않는 날은 전날 21:00까지, 당일 갑자기 타지 않게 되면 12:00까지 대표 전화(031-0000-4580, 차량 담당 내선 3)로 알려 주세요.

  4. 하원 회차는 수업이 끝나는 시각에 맞춰 상담 때 정하며, 회차를 바꾸려면 하루 전까지 데스크에 알려 주세요.
  5. 차량 안에서는 반드시 안전띠를 매고, 간식은 먹지 않습니다.
