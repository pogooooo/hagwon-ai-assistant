# 2026 겨울방학 정규반 변경 시간표

적용 기간: 2026년 12월 28일(월) ~ 2027년 2월 26일(금)

학교마다 방학식 날짜는 다르지만(온빛초 12월 23일, 샘터초 12월 24일, 하늘초·푸른숲초 12월 24일) 학원은 12월 28일(월)부터 일괄하여 아래 방학 시간표로 운영합니다. 12월 24일(목)까지는 2학기 정규 시간표대로 수업합니다. 방학 기간에는 이 변경 시간표가 2학기 정규 시간표를 대신합니다.

## 3. 방학 중 유의 사항

1. 방학 중에는 학교 픽업(등원 회차)이 없습니다. 정류장 등·하원 차량 회차는 12월 셋째 주에 별도 운행표로 안내합니다.
2. 오전반과 오후반을 이어서 듣거나 돌봄 자습반을 이용하는 원생은 도시락을 싸 오며, 점심시간은 12:30~13:00(3층 라운지)입니다.
3. 겨울방학 특강은 정규반과 별도로 신청하며, 정규반 수업과 시간이 겹치는 특강은 신청할 수 없습니다.
4. 12월 31일(목)과 2027년 1월 1일(금)은 연말연시 휴원입니다.
