# 온샘초등종합학원 학원 소개

온샘초등종합학원은 2014년 하늘시 온빛동에서 문을 연 초등 전문 종합학원입니다. 초등학교 1학년부터 6학년까지 국어·수학·영어를 한 곳에서 배우고, 학교 하교 시간에 맞춰 차량으로 데려와 수업과 숙제 지도, 돌봄까지 이어지도록 운영합니다. 종합반은 한 반 10~14명 정원으로 담임 강사가 매일 학습 상황을 확인합니다.

## 3. 입학 상담과 레벨 진단

1. 상담은 평일 11:00~19:00에 받으며, 방문 상담은 하루 전까지 전화로 예약해 주세요.
2. 초3 이상 신입생은 레벨 진단(국어·수학·영어 합쳐 40분, 무료)을 본 뒤 반을 배정합니다. 초1·2는 진단 없이 상담만 합니다.
3. 진단 결과는 진단 다음 날 원장 또는 담임 예정 강사가 전화로 설명드립니다.
4. 등록은 매월 1일 기준이며, 월 중간에 들어오면 남은 수업일수로 일할 계산합니다.

## 5. 차량 운행과 하교 픽업

- 차량 3대(1호차·2호차·3호차)를 운행하며, 온빛초·샘터초·하늘초·푸른숲초 4개 학교 하교 시각에 맞춰 학교 앞에서 원생을 태워 옵니다.
- 모든 차량에 동승 선생님이 함께 탑니다. 노선과 정류장 시각은 「차량 운행 시간표」에 있습니다.
- 위 4개 학교 외 학교는 픽업하지 않으며, 보호자가 직접 등원시켜 주셔야 합니다.

## 6. 학습 관리

- 매월 첫 주에 원생별 학습 분석 리포트(지난달 수학·영어 숙제 채점 결과)를 학부모 앱으로 게시합니다.
- 국어는 서술형 첨삭지로 따로 돌려드립니다.
- 학부모 상담 주간은 학기마다 한 번(2학기는 12월 7일~11일) 운영합니다.
