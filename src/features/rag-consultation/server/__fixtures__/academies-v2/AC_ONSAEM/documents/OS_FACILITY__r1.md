# 온샘초등종합학원 시설 안내

온샘프라자 3층과 4층을 학원으로 쓰고 있습니다. 3층은 저학년 교실과 돌봄실·라운지, 4층은 고학년 교실입니다.

## 1. 층별 안내

| 층 | 공간 | 용도 |
|---|---|---|
| 3층 | 데스크·원장실·상담실 | 등록·상담·결석 연락 접수 |
| 3층 | 301호 | 초1·2 종합반 |
| 3층 | 302호 | 초3 종합반 |
| 3층 | 303호 | 레벨 진단실(신입생 진단·학부모 상담) |
| 3층 | 304호 | 영어 리딩반 전용 교실 |
| 3층 | 305호 | 수학 사고력반 전용 교실(교구실 겸용) |
| 3층 | 306호(돌봄실) | 돌봄 자습반, 24석 |
| 3층 | 라운지 | 간식 시간·하원 대기·보호자 대기 |
| 4층 | 401호~403호 | 초4 종합 1반·2반·3반 |
| 4층 | 404호~406호 | 초5 종합 1반·2반, 초6 종합반 |

## 2. 돌봄실(306호)

- 좌석 24석, 개인 사물함 24칸이 있습니다.
- 운영: 학기 중 월~금 하교 후 ~ 19:00, 방학 중 월~금 09:30~18:00
- 돌봄 교사 2명이 상주하며, 학교·학원 숙제 확인과 독서 지도를 합니다.
- 돌봄실 한쪽에 동화책·학습만화 등 약 1,200권의 독서 코너가 있습니다.

## 3. 라운지와 간식

- 간식은 3층 라운지에서 하루 1회 제공합니다(초1·2 14:00 전후, 초3 이상 각 반 간식 시간).
- 정수기와 손 세정대가 라운지에 있으며, 원생 개인 컵은 사물함에 보관합니다.
- 11월 9일부터 견과류가 들어간 간식은 제공하지 않습니다.

## 4. 안전 시설

- 모든 교실과 복도, 라운지에 CCTV가 설치되어 있습니다(영상 30일 보관).
- 출입구 단말기로 등·하원을 확인하며, 3층 출입문은 수업 시간에 잠금 상태로 운영하고 데스크에서 열어 드립니다.
- 교실마다 공기청정기와 비상 대피 안내도가 있습니다. 소방 대피 훈련은 학기마다 한 번 합니다.

## 5. 주차와 보호자 대기

- 건물 지하 1층 주차장을 쓸 수 있으며, 상담·공개수업으로 방문하시면 데스크에서 1시간 무료 주차 확인을 해 드립니다.
- 등·하원 때 건물 앞 도로는 정차 금지 구역이므로, 직접 데리러 오시는 경우 지하 주차장을 이용하거나 3층 라운지에서 기다려 주세요.

## 6. 기타

- 원생용 와이파이는 제공하지 않습니다. 원생 휴대폰은 수업 중 교실 앞 바구니에 보관합니다.
- 분실물은 데스크에서 2주 동안 보관한 뒤 처리합니다.
