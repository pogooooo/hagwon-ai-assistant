# 2027 온샘 겨울 스키 캠프 안내 (초안 — 원장 결재 전, 게시 금지)

> 실무 검토용 초안입니다. 일정·금액·숙소는 업체 견적 확정 후 바뀔 수 있습니다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 일정 | 2027년 1월 21일(목) ~ 1월 22일(금), 1박 2일 |
| 장소 | 강원 하얀봉 스키리조트(가안) |
| 대상 | 초3~초6 재원생 |
| 정원 | 32명 (선착순) |
| 참가비 | 290,000원 (리프트·장비 대여·강습·숙박·식사 4끼 포함) |
| 신청 마감 | 2026년 12월 4일(금) |

## 2. 일정(안)

- 1일차: 08:00 학원 앞 출발 → 11:00 도착·장비 지급 → 13:00~16:00 단체 강습 → 저녁 레크리에이션
- 2일차: 09:00~12:00 자유 스키(강사 동행) → 13:00 출발 → 16:30 학원 도착

- 형제 참가 시 2번째 원생 20,000원 할인 여부

- 겨울방학 특강(1월 21~22일) 결석 처리 기준
