# 시설 안내 및 실험실 안전 규칙

## 1. 층별 시설

| 층 | 시설 | 안내 |
|---|---|---|
| 4층 | 데스크·상담실 | 출결 단말기, 분실물 보관함 |
| 4층 | 401호·402호·403호 | 중등 내신반 강의실(반별 12석), 403호는 초등 과제 클리닉 겸용 |
| 4층 | 자습실 | 16석, 평일 15:00~22:00 운영, 중등부 원생만 이용 |
| 5층 | 제1실험실 | 초등부 실험실(실험대 4개, 8석) |
| 5층 | 제2실험실 | 중등부 실험실(실험대 6개, 12석), 흄 후드 2대 |
| 5층 | 탐구토론실 | 영재원 대비반 수업, 탐구 발표회 |
| 5층 | 시약 보관실 | 강사·조교만 출입 |

- 자습실 운영 (평일 15:00~22:00, 중등부 원생만 이용)
- 자습실 좌석은 선착순이며, 자리를 30분 이상 비우면 다른 원생이 쓸 수 있습니다.
- 원생용 와이파이는 운영하지 않습니다(학습 앱은 데이터로 이용).
- 4층 복도에 정수기와 개인 컵 보관함이 있습니다. 실험실에는 물병을 가지고 들어갈 수 없습니다.

## 2. 안전 설비

- 제1·제2실험실 공통: 비상 샤워기 1대, 세안기 1대, 소화기 2대, 구급함
- 제2실험실: 흄 후드 2대(냄새·기체가 나는 실험은 흄 후드 안에서만)
- 모든 실험실에 보안경과 실험복을 원생 수만큼 비치합니다. 개인 실험복을 가져와도 됩니다.

## 3. 실험실 안전 규칙

1. 실험실에 들어가면 보안경을 쓰고 실험복을 입습니다. 보안경은 실험이 끝나고 손을 씻을 때까지 벗지 않습니다.
2. 긴 머리는 묶고, 발등을 덮는 신발을 신습니다. 슬리퍼·샌들·크록스는 신을 수 없으며, 실험실 앞에 실내화를 비치해 두었습니다.
3. 음식물과 음료는 실험실에 가지고 들어갈 수 없습니다.
4. 시약은 맛보지 않으며, 냄새는 손으로 부채질하듯 맡습니다.
5. 알코올램프·가스레인지 등 불은 강사가 허락한 뒤에만 켭니다.
6. 유리 기구가 깨지면 손대지 말고 바로 강사나 조교에게 알립니다.
7. 실험이 끝나면 실험대를 정리하고 비누로 손을 씻은 뒤 나갑니다.
8. 다치거나 시약이 몸에 닿으면 바로 알리고, 학원은 응급 조치 후 보호자에게 즉시 연락합니다.
9. 안전 규칙을 지키지 않으면 그날 실험은 참관만 합니다(운영 규정 제5조).

## 4. 실험실 이용 시간

- 실험실은 수업과 실험 보강 시간에만 엽니다. 수업 전후에 원생 혼자 실험실에 머물 수 없습니다.
- 실험 보강: 금요일 초등부 15:00~16:30(제1실험실), 중등부 16:40~18:10(제2실험실)
