# 한결과학학원 학원 소개 및 상담 안내

"직접 해 보고, 끝까지 설명할 수 있는 과학"

한결과학학원은 초등 5학년부터 중학교 3학년까지 과학 한 과목만 가르치는 과학 전문 학원입니다. 모든 과정에서 매달 직접 실험을 하고, 실험 결과를 자기 말로 설명하는 서술형 연습을 함께 합니다. 2019년 개원 이후 가람시 한결구에서 운영하고 있습니다.

## 1. 위치와 오시는 길

| 항목 | 내용 |
|---|---|
| 주소 | 경기도 가람시 한결구 은행나무로 45, 다솜프라자 4층·5층 |
| 4층 | 데스크, 상담실, 강의실(401호·402호·403호), 자습실 |
| 5층 | 제1실험실(초등), 제2실험실(중등), 탐구토론실 |
| 지하철 | 가람선 은행나무역 3번 출구에서 도보 5분 |
| 버스 | '다솜프라자 앞' 정류장 하차(마을버스 7번, 일반버스 31번) |

- 건물 1층에 편의점과 약국이 있는 건물입니다. 엘리베이터를 이용해 4층 데스크로 먼저 오세요.
- 상담 방문 시 건물 지하 주차장을 이용할 수 있으며, 데스크에서 차량 번호를 등록하면 1시간 무료입니다.
- 학원 셔틀버스는 운행하지 않습니다.
- 등·하원 차량은 건물 정문 앞(어린이보호구역)에 정차할 수 없습니다. 건물 후문 쪽 '잠시 정차 구역'을 이용해 주세요.

## 2. 운영 시간

| 구분 | 시간 |
|---|---|
| 평일(월~금) | 14:00~22:00 |
| 토요일 | 10:00~17:00 |
| 일요일·법정 공휴일 | 휴무 |

- 수업은 평일 15:00부터, 토요일 10:00부터 시작합니다.
- 중학생 수업은 경기도 교습 시간 기준에 따라 22:00 이전에 모두 끝납니다.

## 3. 과정 구성

| 과정 | 대상 | 반 | 정원 | 수업 |
|---|---|---|---|---|
| 초등 실험탐구반 | 초5, 초6 | 초5 실험탐구반, 초6 실험탐구반 | 반별 8명 | 주 2회 |
| 영재원 대비반 | 초5·초6 통합 | 영재원 대비반 | 10명 | 주 1회(토요일) |
| 중등 내신반 | 중1~중3 | 학년별 내신A반·내신B반 | 반별 12명 | 주 2회 |
| 과학고 대비반 | 중2·중3 통합 | 과학고 대비반 | 8명 | 주 2회(금·토) |

- **내신A반과 내신B반은 수준별 반이 아닙니다.** 같은 학년의 A반과 B반은 같은 교재로 같은 진도를 나가며, 수업 요일만 다릅니다(A반 월·수, B반 화·목). 담당 강사도 같습니다.
- 영재원 대비반은 교육청·대학 부설 영재교육원 선발(관찰·추천 및 창의적 문제해결력 평가)을 준비하는 반입니다.
- 과학고 대비반은 선발 테스트를 거쳐 들어갈 수 있습니다.
