# 2027년 수강료 개정 안내

학부모님, 안녕하십니까. 한결과학학원입니다.

2027년 1월부터 실험실 기자재(현미경·전원 장치·흄 후드 필터) 교체와 중등부 강사 충원에 따라 수강료를 아래와 같이 조정합니다. 개정 수강료는 **2027년 1월 1일 수강분부터** 적용하며, 2026년 12월 수강분까지는 기존 「2026학년도 수강료 및 실험 재료비 안내」 금액이 그대로 적용됩니다.

- 중등 내신반은 A반·B반의 수강료가 같습니다.

## 2. 실험 재료비

실험 재료비는 이번 개정에 포함되지 않습니다. 2027년에도 2026년 11월 6일자 「실험 재료비 변경 안내」(가정통신문 제2026-11호)의 금액을 그대로 적용합니다.

## 3. 할인과 교재비

- 형제·자매 할인(나이가 어린 원생 월 수강료 10%)과 두 과정 동시 수강 할인(월 20,000원)은 2027년에도 같습니다. 두 할인은 중복되지 않습니다.
- 기본 교재는 계속 수강료에 포함됩니다.

## 4. 자주 묻는 질문

- **12월에 1월분을 미리 내면 예전 금액인가요?** 아닙니다. 납부한 날짜와 관계없이 2027년 1월 수강분부터는 개정 금액이 적용됩니다.
- **겨울방학 특강도 이 금액인가요?** 겨울방학 특강·캠프 비용은 별도로 확정되면 안내드립니다.
