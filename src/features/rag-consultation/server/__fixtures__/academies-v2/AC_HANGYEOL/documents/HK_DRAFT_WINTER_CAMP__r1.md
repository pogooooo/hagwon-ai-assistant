# [초안] 2027 겨울방학 과학 실험 캠프 안내

> 내부 검토용 초안입니다. 원장 승인 전이므로 학부모께 배포하지 마세요. 일정·참가비는 바뀔 수 있습니다.

## 1. 개요

| 항목 | 내용(안) |
|---|---|
| 기간 | 2027년 1월 11일(월) ~ 1월 15일(금), 5일 |
| 시간 | 매일 10:00~15:00 (점심 시간 포함) |
| 대상 | 초5~중1 (재원생·외부생 모두) |
| 정원 | 20명 (선착순) |
| 장소 | 5층 제1실험실·제2실험실 |
| 참가비 | 180,000원 (점심 5회·실험 재료 포함, 재원생 10% 할인 검토 중) |
| 신청 기간 | 2026년 12월 14일(월) ~ 12월 23일(수) |

## 2. 프로그램(안)

| 날짜 | 주제 | 주요 실험 |
|---|---|---|
| 1월 11일(월) | 색이 변하는 화학 | 천연 지시약, 산·염기 마술 |
| 1월 12일(화) | 빛과 렌즈 | 간이 망원경 만들기 |
| 1월 13일(수) | 전기와 자석 | 스피커·전동기 만들기 |
| 1월 14일(목) | 생물 관찰 | 현미경으로 세포 관찰 |
| 1월 15일(금) | 탐구 발표회 | 모둠별 발표와 수료증 |

## 3. 검토 필요 사항

- 점심 업체 확정(1인 8,000원 예상)
- 외부생 모집 홍보 여부
- 담당: 백승호 강사, 우다인 실험 조교
