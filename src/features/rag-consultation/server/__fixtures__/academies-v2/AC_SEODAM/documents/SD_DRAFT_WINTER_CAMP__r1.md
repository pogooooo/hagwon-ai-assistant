# [초안·원장 검토 전] 2027 겨울방학 초등 독서논술 캠프

※ 내부 검토용 초안입니다. 일정·참가비·정원은 확정되지 않았으며 학부모 안내 전 수정될 수 있습니다.

## 1. 캠프 개요

- 주제: "열흘 동안 책 세 권, 글 세 편" — 겨울방학 집중 독서와 글쓰기
- 대상: 초3~초6 (재원생·외부생)
- 기간: 2027년 1월 11일(월) ~ 1월 22일(금), 평일 10일
- 시간: 오전 10:00~12:00 (초3·초4), 오후 13:00~15:00 (초5·초6)
- 장소: 301호 윤동주실, 302호 박경리실

## 2. 참가비와 정원(안)

| 구분 | 내용 |
|---|---|
| 참가비 | 240,000원 (교재·간식 포함) |
| 재원생 할인 | 20,000원 할인 (검토 중) |
| 정원 | 학년별 8명 |
| 신청 | 2026년 12월 10일(목)부터 학부모 앱 (예정) |

## 3. 프로그램(안)

| 주차 | 활동 |
|---|---|
| 1주차 | 동화 한 권 함께 읽기, 인물 인터뷰 글쓰기 |
| 2주차 | 과학 그림책 읽기, 설명하는 글쓰기, 마지막 날 독서 발표회 |

- 캠프 담당: 한서윤 강사, 오민재 강사 (확정 전)
- 확정되면 학부모 앱 공지와 문자로 안내 예정
