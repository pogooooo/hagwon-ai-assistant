3. 시험 뒤 수업

  • 시험이 끝난 뒤 첫 수업은 '시험지 분석 수업'으로 진행합니다. 서담여중 2학년반은 12월 7일(월), 서담중 2학년반은 12월 15일(화), 해솔중 2학년반은 12월 17일(목) 정규 시간에 합니다.
  • 시험지 분석 수업에는 학교 국어 시험지를 꼭 가져와 주세요.
  • 시험 뒤 첫 수업부터는 정규 시간표로 돌아갑니다.

4. 유의 사항

  • 연장 수업, 토요 내신 클리닉, 시험 직전 대비 수업은 추가 수강료 없이 진행합니다.
  • 시험 기간 중 휴강한 회차는 따로 보강하지 않고 시험 직전 대비 수업으로 대신합니다.
  • 변경 시간표 기간에는 결석해도 수업 영상을 제공하지 않으며, 결석한 내용은 질문 클리닉(토 12:00~13:00, 304호 이육사실)에서 보충합니다.
  • 11월 19일(목) 수능일 휴강과 보강은 「11월 휴강·보강 안내」를 따릅니다.
