# 서담국어논술학원 강사 소개

2026학년도 2학기 기준 담당 반과 상담 가능 시간입니다. 강사 상담은 데스크(031-0000-5252)로 예약해 주시면 담당 강사가 예약한 시간에 학원 전화로 연락드립니다. 강사 개인 휴대폰 번호는 안내하지 않습니다.

## 강지원 원장

- 담당: 고1 수능국어반, 고2 수능국어반, 고등 1:1 첨삭
- 약력: 국어교육 전공, 수능 국어 강의 경력 16년
- 상담 가능 시간: 화·목 17:00~19:00
- 한마디: "지문을 빨리 읽는 법보다 정확히 읽는 법을 먼저 가르칩니다."

## 한서윤 강사

- 담당: 초3 독서논술반, 초4 독서논술반
- 약력: 아동문학 전공, 독서지도 경력 9년
- 상담 가능 시간: 수 15:00~17:00
- 한마디: "책 이야기를 즐겁게 나누는 것에서 글쓰기가 시작됩니다."

## 오민재 강사

- 담당: 초5 독서논술반, 초6 독서논술반, 초등·중등 1:1 첨삭
- 약력: 국어국문학 전공, 논술 지도 경력 7년
- 상담 가능 시간: 금 15:00~17:00
- 한마디: "주장보다 근거, 근거보다 예시를 꼼꼼히 봅니다."

## 백승희 강사

- 담당: 서담중 2학년반, 서담여중 2학년반
- 약력: 국어교육 전공, 중등 내신 지도 경력 11년
- 상담 가능 시간: 금 16:00~18:00
- 한마디: "학교별 교과서와 기출 경향에 맞춰 문법까지 빈틈없이 준비합니다."

## 임도현 강사

- 담당: 중1 국어 기본반, 해솔중 2학년반, 중3 내신·고입 국어반
- 약력: 국어국문학 전공, 중등 국어 지도 경력 8년
- 상담 가능 시간: 월 16:00~17:30
- 한마디: "중학교 국어의 기본기를 고등학교까지 이어지게 만듭니다."

## 데스크
