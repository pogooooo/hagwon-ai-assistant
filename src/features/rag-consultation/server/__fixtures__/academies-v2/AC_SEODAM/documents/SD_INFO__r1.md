# 서담국어논술학원 학원 소개

서담국어논술학원은 2019년 3월 문을 연 초등 3학년부터 고등 2학년까지의 국어·독서논술 전문 학원입니다. "읽은 만큼 생각하고, 생각한 만큼 쓴다"를 원칙으로 학년별 독서논술, 학교별 국어 내신, 수능 국어, 1:1 논술 첨삭을 운영합니다.

| 지하철 | 가람선 서담역 2번 출구에서 도보 4분 |

| 주차 | 건물 지하 1~2층 주차장. 상담 방문 시 1시간 무료(데스크에서 차량 번호 등록) |
