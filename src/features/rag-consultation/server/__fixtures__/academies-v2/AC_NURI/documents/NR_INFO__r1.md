# 누리코딩아카데미 학원 안내

누리코딩아카데미는 초등학교 3학년부터 고등학교 1학년까지 코딩과 정보 과목을 가르치는 레벨제 학원입니다. 블록 코딩(스크래치·엔트리)에서 시작해 파이썬, 알고리즘, 앱 만들기 프로젝트까지 단계별로 이어지도록 과정을 나누었습니다. 모든 정규 과정은 8주를 한 기수로 운영합니다.

## 1. 위치와 오시는 길

- 주소: 경기도 용인시 수지구 누리로 128, 누리스퀘어 5층 (501~505호)
- 지하철: 신분당선 동천역 2번 출구에서 도보 7분
- 버스: 마을버스 15번 '누리스퀘어' 정류장 하차, 건물 정문 바로 앞
- 주차: 건물 지하 주차장을 이용하실 수 있습니다. 상담이나 레벨테스트로 방문하시면 1시간 무료 주차권을 드립니다.

## 2. 운영 시간

| 구분 | 운영 시간 |
|---|---|
| 평일(월~금) | 13:00~21:30 |
| 토요일 | 09:30~19:30 |
| 일요일·법정 공휴일 | 휴무 |

- 데스크 전화 상담: 평일 13:00~21:00, 토요일 09:30~18:00 (대표 전화 031-0000-5858)
- 방문 상담은 예약제로 운영합니다: 평일 14:00~20:00, 토요일 10:00~17:00
- 카카오톡 채널 '누리코딩아카데미'에서도 상담 예약과 문의를 받습니다. 카카오톡 문의는 운영 시간 안에 순서대로 답변드립니다.

## 3. 과정 체계(레벨제)

| 레벨 | 과정 | 대상 | 주요 내용 |
|---|---|---|---|
| L1 | L1 스크래치 기초반 | 초3~초4 | 블록 코딩 기초, 동작·이벤트·반복 블록 |
| L2 | L2 스크래치 심화반 | 초4~초5 | 변수·리스트·복제를 활용한 게임 만들기 |
| 메이커 | 엔트리 메이커반 | 초4~초6 | 엔트리와 센서 보드로 생활 속 문제 해결 작품 만들기 |
| L3 | L3 파이썬 기초반 | 초6~중1 | 파이썬 문법 기초(입출력, 조건문, 반복문, 리스트) |
| L4 | L4 파이썬 응용반 | 중1~중2 | 함수·파일·클래스, 라이브러리 활용 |
| L5 | L5 알고리즘 평일반 / L5 알고리즘 토요반 | 중1~중2 | 자료구조와 기초 알고리즘(정렬, 탐색, 재귀) |
| L6 | L6 알고리즘 토요반 | 중2~고1 | 정보올림피아드 대비 고급 알고리즘 |
| 프로젝트 | 앱 만들기 프로젝트반 | 중2~고1 | 팀 프로젝트로 웹앱을 기획·제작·발표 |

- L5 알고리즘 평일반과 L5 알고리즘 토요반은 같은 커리큘럼으로 진행하며, 수업 요일과 1회 수업 시간만 다릅니다.
- 학년은 권장 기준이며, 실제 반 배정은 레벨테스트 결과로 정합니다.

## 4. 신규 상담과 레벨테스트

1. 신규 원생은 레벨테스트를 본 뒤 반을 배정합니다. 레벨테스트는 무료이며 약 50분(코딩 실습 30분 + 학부모 상담 20분)이 걸립니다.
2. 코딩을 처음 배우는 초3~초4 원생은 레벨테스트 없이 L1 스크래치 기초반에 바로 등록할 수 있습니다.
3. 레벨테스트는 대표 전화 또는 카카오톡 채널로 예약합니다. 노트북은 학원 장비를 사용하므로 따로 가져오지 않아도 됩니다.
4. 레벨테스트 결과는 상담 당일 바로 안내하며, 추천 반과 다음 기수 모집 현황을 함께 알려 드립니다.

## 5. 기수 운영

- 1년을 6개 기수로 나누어 운영하며, 한 기수는 8주입니다.
- 2026년 하반기 기수: 4기 7월 6일~8월 29일, 5기 9월 7일~10월 31일, 6기 11월 2일~12월 26일
- 기수가 끝나기 전 마지막 주에 레벨 평가를 보고, 결과에 따라 다음 기수 반을 정합니다.
