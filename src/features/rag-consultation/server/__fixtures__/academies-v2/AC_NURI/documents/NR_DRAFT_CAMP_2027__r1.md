# [초안·원장 검토 전] 2027 여름 싱가포르 코딩 캠프 안내

> 내부 검토용 초안입니다. 원장 승인 전이므로 학부모님께 배포하지 않습니다. 일정·비용은 여행사 견적에 따라 바뀔 수 있습니다.

## 1. 캠프 개요

| 항목 | 내용(안) |
|---|---|
| 기간 | 2027년 7월 26일(월) ~ 8월 1일(일), 6박 7일 |
| 대상 | 중1~고1 재원생 |
| 모집 인원 | 20명(최소 출발 인원 12명) |
| 참가비 | 2,980,000원(항공·숙박·식사·프로그램 포함) |
| 인솔 | 정다운 원장, 노은비 강사 |

## 2. 프로그램(안)

- 현지 대학 컴퓨터공학과 코딩 워크숍(3일)
- 국제 학생 해커톤 참가(2일)
- IT 기업 견학과 시내 탐방(1일)

## 3. 일정(안)

- 학부모 설명회: 2027년 3월 중
- 참가 신청과 계약금 500,000원 납부: 2027년 4월 말까지
