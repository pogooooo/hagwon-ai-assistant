# 2027년 과정 수강료 개정 안내

학부모님 안녕하세요. 누리코딩아카데미입니다.

강의실 장비 교체와 교재 개정에 따라 2027년 7기(2027년 1월 4일 개강)부터 과정 수강료를 아래와 같이 조정합니다. 2026년 6기(12월 26일 종강)까지는 현행 수강료가 그대로 적용됩니다. 수강료는 지금과 같이 8주(한 기수) 단위로 냅니다.

## 1. 개정 수강료 (8주 기준, 7기부터 적용)

| 과정 | 현행 수강료(6기까지) | 개정 수강료(7기부터) | 교재비(7기부터) |
|---|---|---|---|
| L1 스크래치 기초반 | 280,000원 | 290,000원 | 15,000원 |
| L2 스크래치 심화반 | 300,000원 | 310,000원 | 15,000원 |
| 엔트리 피지컬반(구 엔트리 메이커반) | 240,000원 | 260,000원 | 16,000원 |
| L3 파이썬 기초반 | 360,000원 | 370,000원 | 18,000원 |
| L4 파이썬 응용반 | 380,000원 | 390,000원 | 20,000원 |
| L5 알고리즘 평일반 | 400,000원 | 420,000원 | 20,000원 |
| L5 알고리즘 토요반 | 400,000원 | 420,000원 | 20,000원 |
| L6 알고리즘 토요반 | 450,000원 | 470,000원 | 22,000원 |
| 앱 만들기 프로젝트반 | 420,000원 | 440,000원 | 없음 |

- L4 파이썬 응용반 교재는 2027년 개정판으로 바뀌면서 교재비가 18,000원에서 20,000원으로 오릅니다. 다른 과정의 교재비는 바뀌지 않습니다.
- 엔트리 피지컬반의 마이크로비트 키트 비용은 수강료·교재비와 별도이며, 「2027년 과정 개편 안내」를 참고해 주세요.

## 2. 노트북 대여료

노트북 대여료는 8기(2027년 3월 2일 개강)부터 8주 45,000원으로 조정합니다. 7기까지는 현행 노트북 대여료(8주 40,000원)가 그대로 적용됩니다.

## 3. 7기 등록과 납부

| 구분 | 기간 |
|---|---|
| 재원생 우선 등록 | 2026년 12월 7일(월) ~ 12월 12일(토) |
| 신규 원생 등록 | 2026년 12월 14일(월)부터, 정원이 차면 대기 접수 |
| 7기 수강료 납부 | 2026년 12월 21일(월) ~ 2027년 1월 4일(월) |
| 7기 수업 기간 | 2027년 1월 4일(월) ~ 2월 27일(토), 8주 |

- 재원생 우선 등록 기간이 지나면 남은 자리는 신규 원생과 같은 순서로 배정합니다.
- 수강료 반환 기준은 바뀌지 않으며 「운영 규정」 제4조를 따릅니다.
