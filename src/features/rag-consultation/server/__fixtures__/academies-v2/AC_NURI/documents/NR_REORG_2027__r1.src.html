2027년 과정 개편 안내

학부모님께. 2027년 7기(1월 4일 개강)부터 일부 과정을 아래와 같이 개편합니다. 궁금한 점은 11월 28일(토) 학부모 설명회나 데스크로 문의해 주세요.

1. 엔트리 메이커반 → 엔트리 피지컬반

엔트리 메이커반은 7기부터 '엔트리 피지컬반'으로 이름을 바꾸고, 마이크로비트 보드를 활용한 피지컬 컴퓨팅 중심으로 운영합니다. 수업 요일과 시간(토 10:00~12:00)은 그대로입니다.

마이크로비트 키트(보드와 센서 세트)는 처음 수강할 때 한 번만 구입하며, 키트 비용은 38,000원입니다. 이미 키트를 가지고 있는 원생은 구입하지 않아도 됩니다.

2. 레벨 승급 기준

6기 레벨 평가부터 승급 기준을 점수로 정합니다. 레벨 평가 70점 이상이면 다음 레벨로 승급합니다.

레벨 평가 점수결과
70점 이상다음 레벨로 승급
60점 ~ 69점담당 강사 상담 후 결정
60점 미만같은 레벨 재수강

6기 레벨 평가는 12월 21일(월)부터 12월 26일(토)까지 각 반 8주 차 정규 수업 시간에 진행합니다. 앱 만들기 프로젝트반은 12월 28일(월) 보강 수업 시간에 진행합니다.

3. 앱 만들기 프로젝트반 정원 조정

7기부터 앱 만들기 프로젝트반 정원을 8명에서 10명으로 늘리고, 2인 1팀 프로젝트로 운영합니다.

4. L6 알고리즘 토요반 모의고사

7기부터 L6 알고리즘 토요반은 기수마다 정보올림피아드 형식 모의고사를 2회(4주 차, 8주 차) 실시합니다. 모의고사는 정규 수업 시간에 3시간 동안 진행하며 추가 비용은 없습니다.
