# 누리코딩아카데미 강사 소개

| 강사 | 담당 과정 |
|---|---|
| 정다운 원장 | L6 알고리즘 토요반 |
| 서윤재 강사 | L1 스크래치 기초반, L2 스크래치 심화반, 엔트리 메이커반 |
| 마하늘 강사 | L3 파이썬 기초반, L4 파이썬 응용반 |

## 정다운 원장

- 담당: L6 알고리즘 토요반, 정보올림피아드 진학 상담
- 컴퓨터공학을 전공했고, 중·고등학생 정보올림피아드 지도를 12년째 하고 있습니다.
- "문제를 읽고 바로 코드를 쓰기보다, 풀이를 말로 설명할 수 있을 때까지 생각하는 습관을 가장 중요하게 봅니다."

## 서윤재 강사

- 담당: L1 스크래치 기초반, L2 스크래치 심화반, 엔트리 메이커반
- 초등 컴퓨팅 교육 8년. 초등학교 방과후 코딩 강사로 일했습니다.
- 블록 코딩 작품을 만든 뒤 친구들 앞에서 발표하는 시간을 매 수업 마지막 10분에 둡니다.

## 마하늘 강사

- 담당: L3 파이썬 기초반, L4 파이썬 응용반
- 소프트웨어 회사에서 웹 서비스 개발자로 5년 일한 뒤 학원 강의를 시작했습니다.
- 수업마다 '오늘의 오류' 시간을 두어 원생들이 자주 내는 오류 메시지를 함께 읽고 고칩니다.

## 권태오 강사

- 담당: L5 알고리즘 평일반, L5 알고리즘 토요반
- 대학 시절 프로그래밍 대회 동아리 대표를 지냈고, 알고리즘 입문 지도 6년 경력입니다.
- 매주 온라인 채점 시스템(누리 저지)으로 과제를 내고, 틀린 문제는 다음 수업 첫 20분에 함께 풉니다.

## 노은비 강사

- 담당: 앱 만들기 프로젝트반
- 모바일 앱 스타트업에서 프런트엔드 개발자로 일했습니다.
- 2인 1팀으로 기획부터 발표까지 진행하며, 기수마다 팀별 시연 영상을 남깁니다.

## 코딩 질문방 조교

- 대학생 조교 2명이 코딩 질문방에서 과제 질문을 받습니다.
