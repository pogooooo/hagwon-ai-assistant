# RAG 상담 300문항 평가

가상 학원 3곳에서 100문항씩, 총 **300문항**을 구성했습니다. 문항 하나는 상담 질문 하나입니다. 두 엔진에 같은 질문과 원본을 주고, 최초 실행 전에 고정한 정답과 실제 답변·인용을 비교했습니다. 기존 평가와 문항·원본이 겹치는지도 검사했습니다.

## 1. 문항 선정 기준

요금, 시간표, 학습 리포트, 행사 안내처럼 승인 자료를 근거로 답해야 하는 질문을 골랐습니다. 비슷한 반 이름, 다른 적용 날짜, 같은 제목의 다른 행사 회차, 접근 권한 밖 자료를 함께 두어 질문과 근거를 정확히 연결하는지 확인했습니다. 근거가 모두 있는 질문, 일부만 확인되는 질문, 답변을 보류하거나 거부해야 하는 질문을 포함했습니다.

| 유형                | 문항 수 | 확인 항목                                                              |
| ------------------- | ------: | ---------------------------------------------------------------------- |
| 수강료·재료비       |      36 | 반별 수강료 18, 수강료와 재료비를 함께 묻는 질문 18                    |
| 담당 강사           |      18 | 단일 반 15, 두 반 각각 3                                               |
| 복합 질문           |      36 | 비용과 강사 18, 비용과 시간표 18                                       |
| 시간표              |      36 | 수업이 있는 지정 요일 18, 수업이 없는 요일 18                          |
| 부분 응답·미래 요금 |      36 | 일부 정보만 확인되는 질문 18, 다음 달 적용액 18                        |
| 학습 리포트         |      90 | 단원 정답률 36, 기록된 학습 방향 18, 권한 거부 18, 미공개 월 18        |
| 행사 공지           |      48 | 행사 안내 6, 날짜 지정 6, 다른 회차 12, 날짜·요일 충돌 12, 스캔 PDF 12 |
| **합계**            | **300** | 학원당 100문항                                                         |

## 2. 채점 방법

문항마다 기대 응답 상태, 답변에 들어갈 필수 사실, 인용해야 할 출처와 위치를 미리 정했습니다. 슬롯 v4.1 채점기는 요청 항목별로 다음을 확인합니다.

1. **응답 상태**가 정답과 같아야 합니다. 전체 답변, 부분 답변, 보류, 권한 거부를 구분합니다. 부분 답변에서는 누락 항목 목록도 맞아야 합니다.
2. **필수 사실**이 모두 맞아야 합니다. 답변 줄에서 반·기간·수치·단위가 같은 조건으로 묶였는지 대조합니다. 비용과 시간표를 함께 묻는 문항에서 둘 다 답할 근거가 있으면 두 항목을 모두 맞혀야 합니다.
3. **최종 인용**이 맞아야 합니다. 출처 ID와 지정된 쪽·문단·표 행·열을 대조하고, 실제 인용한 내용이 필수 사실을 뒷받침하는지 확인합니다. 한 사실에 여러 근거가 필요하면 지정된 묶음 전체를 확인합니다.
4. **금지값·추가 내용·권한 조건**을 확인합니다. 다른 반이나 날짜의 금지값, 정답에 없는 추가 주장·인용, 권한 밖 또는 미승인 자료 사용이 확인되면 실패입니다. 문항별 생성 호출 상한도 검사했습니다.

모든 조건을 만족하면 문항당 1점입니다. **정답률은 정답 문항 수 ÷ 300 × 100**으로 계산했습니다. 이 세트에서는 **285문항 이상 정답과 권한·승인 위반 0건**을 요구합니다. 정상 문항에서 모의 생성을 호출한 실행도 통과할 수 없습니다. [채점 코드](server/eval/scoring-v4.ts) · [통과 조건](server/eval/holdout-review.ts)

## 3. 평가 결과

| 엔진      |        정답 |    정확도 |
| --------- | ----------: | --------: |
| 기본 엔진 |     144/300 |     48.0% |
| 계획 엔진 | **288/300** | **96.0%** |

계획 엔진의 오답 12문항은 모두 스캔 PDF 행사 문항이었습니다. 두 엔진 모두 권한·승인 위반과 생성 호출은 각각 0건이었습니다.
