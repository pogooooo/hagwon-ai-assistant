# RAG 기술 적용 및 실험 기록

## 목표와 판단 기준

목표는 개발에 사용하지 않은 학원 자료의 독립 평가에서 문항 정답률 95% 이상입니다. 공개 393문항은 기존 동작과 어려운 사례의 변화 확인에 사용합니다. 같은 공개 세트의 기준으로 환산하면 374/393 이상이며, 합성 300문항은 회귀 전용입니다. 전체 채점·보안 조건은 [TEST_REPORT.md](TEST_REPORT.md)를 따릅니다.

## 유지한 기술

| 기술                       | 적용과 근거                                                                                                                                                             |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ACL 선필터 + BM25          | 승인·유효한 자료를 권한 범위 안에서만 검색합니다. 구형 동일 실험에서 BM25와 e5 하이브리드·bge 재정렬은 207/393으로 동률이었고 p95는 각각 7.8ms, 117ms, 2,156ms였습니다. |
| 비용·시간표의 원본 셀 검증 | 반·적용 시점·필드별로 행과 열을 검증합니다. 직전 217/393에서 시간표 근거 경로 적용 후 221/393을 기록했고 기존 정답 손실은 없었습니다.                                   |
| PDF 표 스키마·희소 셀 보존 | 머리글이 다른 다음 페이지의 표와 빈 기간 셀을 보존합니다. 생성 PDF 회귀로 두 오류를 재현하고 검증했습니다. 공개 393 전체 점수는 그대로였습니다.                         |
| 복합 질문 분리·부분 답변   | 독립 항목을 별도로 검증하고, 누락을 표시합니다. 비용 근거만 있을 때 강사를 지어내지 않는 재현 테스트로 확인했습니다.                                                    |
| 선택적 생성 포트           | Gemini와 CLOVA를 연결할 수 있습니다. 공개 요금·일정의 기본 경로는 정형/인용 답변입니다. 운영 경로에서 개인 학습 자료의 외부 전송을 차단합니다.                          |

이번 작업에서 두 가지를 추가했습니다. 수강료는 요청 연도 안에서 승인된 첫 개정 적용일을 찾고, 그 날짜에 유효한 금액이 충돌하는지 다시 확인합니다. 시간표는 강좌명과 별도 대상 학년 열을 결합하고, 현재 승인 사실에 연결된 출처가 있으면 그 출처의 표를 사용합니다. 직전 221/393에서 224/393으로 상승했고, 합성 회귀는 300/300입니다. 새 정답은 NR-T-013, SD-T-107, OS-T-021이며 새 오답은 없었습니다.

## 비교했으나 기본 경로에서 제외한 기술

이번 검색 실험은 같은 공개 393·합성 300문항, OCR 캐시, BM25, 계획 엔진, Mock 생성과 기존 채점을 사용했습니다. 각 변형은 하나씩 적용한 후 제거했습니다. 비교 기준은 221/393, 300/300입니다.

| 변형                                 |      공개 393 |  합성 300 | 판단                                                                                        |
| ------------------------------------ | ------------: | --------: | ------------------------------------------------------------------------------------------- |
| 답변 후보 그룹 탐색 상한 확대        |           221 |       300 | 정답 증감 0. 더 넓은 그룹을 뒤질 근거 없음                                                  |
| 일반 답변의 추정 값 유형을 모두 강제 |           221 |       300 | 정답 증감 0, 오보류 19.2% → 19.9%. 추정 유형을 필수 슬롯으로 그대로 쓰지 않음               |
| 기본 BM25 후보 8 → 16                |           221 |       300 | 정답 증감 0. 인용 정확도 80.6% → 81.1%였지만 로컬 p95 9.9 → 10.7ms. 기본 폭 유지            |
| 절 제목보다 본문 키워드 일치 우선    |           221 |       300 | 정답 증감 0. 기존 순서 유지                                                                 |
| 전체 Gemini 답변                     |           237 |    미실행 | 정책·인용·숫자 검증 후 16문항 순증. 81문항을 새로 맞히고 65문항을 잃었으므로 기본 전환 제외 |
| e5 하이브리드·bge 재정렬             | 과거 각각 207 | 해당 없음 | 과거 동일 조건 BM25와 동률, 지연과 메모리 증가. 실험 옵션은 재현용으로 유지                 |

두 개선을 포함한 동일 코드에서 BM25 길이 정규화 b=0.75를 다시 대조했습니다. b=0.4는 224 → 222로 떨어졌고, b=1은 224 → 225였지만 구어체 회귀가 74 → 73으로 내려갔습니다. 합성 300은 두 변형 모두 유지됐습니다. 기본 b=0.75를 유지합니다.
저장된 동일 393문항 응답을 후처리하여 기존 엔진이 보류한 문항만 Gemini 결과로 대체하면 234/393, 보류·담당자 연결·확인 질문을 모두 대체하면 236/393, 보류·부분 답변을 대체하면 235/393입니다. 이미 채점한 결과를 조합한 공개 자료 분석입니다. 실행 중 외부 호출이나 개인정보 처리 경로로 추가하지 않았습니다. 정답을 미리 알고 두 결과 중 정답만 고르는 이상적 선택도 302/393(76.8%)입니다. 현재 두 경로 사이의 선택만으로는 95%에 도달할 수 없습니다.

다음 검증에서는 문항별 필수 셀을 직접 제공했을 때와 검색 결과를 사용했을 때를 비교해 파싱·검색·결합 중 실패 단계를 분리합니다. 이후 개발에 사용하지 않은 학원 문서와 사람 검수 질문으로 확인합니다.

## Git 추적 파일의 실행 용도

다음은 배포 앱의 요청 처리에 직접 필요하지 않은 파일입니다. 개발 서버, 테스트, CI에 필요한 범위는 따로 표시합니다.

| 경로                                                                               | 용도와 유지 이유                                                    |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 루트 README.md, CONTRIBUTING.md, .github/pull_request_template.md                  | 설명·협업 문서                                                      |
| 이 폴더의 README.md, DEMO.md, REPORT.md, TEST_REPORT.md, RAG_TECHNIQUES.md         | 실행·설계·평가 설명                                                 |
| server/**fixtures**/eval-results/                                                  | 과거 평가 출력 116개. 운영 입력이 아닌 비교 기록                    |
| server/**fixtures**/academies-v1/, academies-v2/, axr-synthetic-v1/, documents-v1/ | 가상 문항·문서·시험 자료. 테스트에 사용하며 일부는 개발 서버가 읽음 |
| server/**tests**/, server/eval/, server/generation/smoke-provider.ts               | 회귀 테스트, 평가 CLI, 공급자 연결 진단                             |
| server/dev/                                                                        | 개발 서버와 화면. npm run rag:dev 실행에 필요                       |
| .github/workflows/ci.yml, .husky/, .vscode/, .editorconfig, ESLint·Prettier 설정   | CI, 커밋 검사, 편집기·정적 검사 설정                                |
| .env.example, .node-version, .nvmrc, .npmrc                                        | 환경 변수 예시와 재현 가능한 개발 환경 설정                         |
| public/.gitkeep, src/components/.gitkeep                                           | 빈 디렉터리 보존용                                                  |

package.json, 잠금 파일, Next.js·TypeScript·Capacitor 설정은 설치·빌드·패키징에 영향을 주므로 위 목록에 넣지 않았습니다. 파일은 분류만 했습니다.
