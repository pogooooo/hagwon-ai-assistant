# RAG 기술 적용 및 실험 기록

## 목표와 판단 기준

목표는 개발에 사용하지 않은 학원 자료의 독립 평가에서 문항 정답률 95% 이상입니다. 공개 393문항은 기존 동작과 어려운 사례의 변화 확인에 사용합니다. 같은 공개 세트의 기준으로 환산하면 374/393 이상이며, 합성 300문항은 회귀 전용입니다. 전체 채점·보안 조건은 [TEST_REPORT.md](TEST_REPORT.md)를 따릅니다.

## 비교했으나 기본 경로에서 제외한 기술

이번 검색 실험은 같은 공개 393·합성 300문항, OCR 캐시, BM25, 계획 엔진, Mock 생성과 기존 채점을 사용했습니다. 각 변형은 하나씩 적용한 후 제거했습니다. 비교 기준은 221/393, 300/300입니다.

두 개선을 포함한 동일 코드에서 BM25 길이 정규화 b=0.75를 다시 대조했습니다. b=0.4는 224 → 222로 떨어졌고, b=1은 224 → 225였지만 구어체 회귀가 74 → 73으로 내려갔습니다. 합성 300은 두 변형 모두 유지됐습니다. 기본 b=0.75를 유지합니다.
저장된 동일 393문항 응답을 후처리하여 기존 엔진이 보류한 문항만 Gemini 결과로 대체하면 234/393, 보류·담당자 연결·확인 질문을 모두 대체하면 236/393, 보류·부분 답변을 대체하면 235/393입니다. 이미 채점한 결과를 조합한 공개 자료 분석입니다. 실행 중 외부 호출이나 개인정보 처리 경로로 추가하지 않았습니다. 정답을 미리 알고 두 결과 중 정답만 고르는 이상적 선택도 302/393(76.8%)입니다. 현재 두 경로 사이의 선택만으로는 95%에 도달할 수 없습니다.

다음 검증에서는 문항별 필수 셀을 직접 제공했을 때와 검색 결과를 사용했을 때를 비교해 파싱·검색·결합 중 실패 단계를 분리합니다. 이후 개발에 사용하지 않은 학원 문서와 사람 검수 질문으로 확인합니다.

## 후속 채택 · 지도 기록과 대상 학년

- 강사가 이미 안내한 학습 지도를 묻는 요청은 승인 지도 사실만 읽습니다. 보고서 발행 기준 월과 계획 시행 월을 구분하고, 요청 범위의 기록을 찾지 못하면 보류합니다. 이 경로는 생성 모델을 호출하지 않습니다.
- 비용표에서 강좌와 대상 학년이 다른 셀에 있을 때 두 셀을 함께 묶고 학기당 금액을 보존합니다. 시간표에서 한 학년과 강좌가 명확하면 카탈로그에서 두 조건이 함께 맞는 반을 고릅니다. 복수 반 요청에는 이 좁힘을 적용하지 않습니다.

공개 393문항에서 224 → 230으로 증가했습니다. 상세 문항과 회귀 지표는 [TEST_REPORT.md](TEST_REPORT.md)에 있습니다.

## 후속 채택 · 과목별 성적과 회차권

승인 보고서의 학생·기간·버전을 확인하고, 같은 표 행에서 과목·지표·값을 확인합니다. 두 기간을 비교할 때는 각각의 원본 행을 인용합니다. 회차권은 같은 서비스의 요청 회차와 금액 셀을 연결합니다. 이 두 변경은 공개 회귀 4문항을 회복했습니다. [TEST_REPORT.md](TEST_REPORT.md)

## 후속 채택 · 주차별 커리큘럼과 부대 요금

커리큘럼은 반·주차·학습 항목을 원본 표 행에 함께 묶고, 같은 대상의 승인 자료가 충돌하면 보류합니다. 대여료·통학 차량비는 서비스명과 조건에 맞는 원본 금액 셀을 사용합니다. 시간표는 학년 조건을 유지하고 강의실과 시각을 같은 행에서 검증합니다. 별도 자료에서 상담 비서에게 답변을 강제하는 지시가 섞이면 근거 후보에서 제외합니다. 공개 회귀에서 정답 5문항이 늘었습니다. [TEST_REPORT.md](TEST_REPORT.md)

## 후속 채택 · 주차별 환불 구간

승인 표의 시작·종료 경계를 해석해 요청 주차가 속한 행의 반환 비율만 답합니다. 같은 주차의 승인 규정이 충돌하면 보류합니다. 공개 회귀에서 1문항을 회복했습니다. 미래 효력 문서의 기수별 납부 기간 조회는 현재 승인 자료의 검색·인용 조건에서 공개 점수 개선이 없어 제외했습니다.

## 후속 채택 · 미래 납부 일정과 학습 판단

기수별 납부 기간은 현재 승인된 공개 문서 중 93일 이내 적용 예정 자료를 명시적으로 허용합니다. 승인을 미래로 당기지 않고, 응답의 출처는 실제 질의 시점의 권한·승인·리비전과 문서의 적용 시점을 분리하여 확인합니다. 이로써 앞선 단순 납부 행 조회에서 제외됐던 문항을 회복했습니다. 재원생의 등원 시각은 날짜에 맞는 반별 수업 표를 사용하며, 개인의 학습 태도·원인·결과 예측은 정형 학원 정보로 대체하지 않습니다. 공개 회귀에서 5문항을 회복했습니다.

## 후속 채택 · 미제출과 납부 조건

제출된 학습 분석 자료만으로는 미제출 횟수를 알 수 없으므로 해당 질문은 보류합니다. 카드 결제 가능 여부, 할부 가능 여부, 납부 기한을 분리하고 승인 문서가 직접 뒷받침하는 항목만 답합니다. 이 변경은 공개 회귀 3문항을 회복했습니다.

## 후속 채택 · 질문의 대상과 필요한 근거

길 안내는 주소와 요청한 교통수단을 함께 확인합니다. 교통 근거만 우선한 중간 변형에서 주소가 누락돼 개발 정답 하나가 줄었고, 주소 행을 별도로 보존해 이를 복구했습니다. 학습 보고서의 취약 영역 판정, 반별 동일 청구 기준의 교재비, 날짜·반이 일치하는 대체 수업 공지는 각각 원본 근거를 우선합니다. 통합 공개 회귀에서 6문항을 회복했습니다.

## 후속 채택 · 기간·대상 범위와 예측 보류

방학 운행표의 시즌을 확인하고 학기 중 시각을 가져오지 않습니다. 명시된 같은 학년의 여러 반은 각각 시간표 행을 확인합니다. 대기 현황과 학습 성적을 미래 입학 시점·시험 점수의 근거로 사용하지 않습니다. 수강료와 간식비는 각각의 승인 근거를 확인하고, 개정 요금은 수강료와 출처·적용 시작일이 일치할 때만 사용합니다. 공개 회귀에서 새 정답 5문항을 확인했습니다.

## 후속 채택 · 시설 운영 시간과 복합 요청

시설명은 원본 절 제목이나 같은 문서의 바로 앞 제목에서, 운영 시간은 해당 문장에서 확인합니다. 입학 진단은 문서에 쓰인 표현까지 검색합니다. 할인 예시의 등록 반·산식을 검증하고, 일반 시간표와 별도 유형 수업에 필요한 근거를 분리합니다. 공개 회귀에서 새 정답 4문항을 확인했습니다.

## 후속 채택 · 담당 강사와 소개 항목 연결

카탈로그가 확인한 반의 승인 담당 강사 사실을 먼저 조회합니다. 같은 승인 출처에서 일치하는 강사 이름의 절·문단 또는 표 행을 찾고, 질문이 요청한 경력·상담 시간·학력만 확인합니다. 다른 강사, 다른 개정판, 초안, OCR 검수 대상은 제외합니다. 명시된 다른 강사를 담당자로 대체하거나 출처가 충돌하는 속성을 임의로 선택하지 않습니다. 검색 점수만으로 주변 강사 소개를 이어 붙이면 비슷한 이름이나 시간대를 잘못 답할 수 있으므로 이 경로는 이름과 원본 위치를 확인한 인용만 허용합니다.

이 변경은 공개 393문항에서 4개, 구어체 100문항에서 1개를 회복했습니다. 재현 테스트는 다른 강사의 경력·상담 시간, 미승인 개정판과 학력 누락, 표 열 인용을 검사합니다. 별도 생성 호출이 필요하지 않습니다.

## 후속 제외 · 본문 검색과 순위 결합

강사 개선을 포함한 같은 엔진·채점·OCR 캐시로 검색 순위만 바꿨습니다. 기존 BM25는 본문과 제목·절·대상·기간 메타데이터를 함께 색인합니다. 본문 전용 BM25와, 두 순위를 `k=60` RRF로 합친 변형을 비교했습니다. 각 후보는 같은 승인·권한 필터를 통과했으며 외부 모델을 호출하지 않았습니다.

## 후속 채택 · 적용 시점과 복합 질문의 독립 검증

- 서버 대화 상태에 실제 인용한 리포트의 과목·기간과 승인 시험일을 저장합니다. 학생이 바뀌면 이전 학생의 단원을 그대로 적용하지 않고, 새 학생의 권한과 같은 기간의 리포트를 다시 확인합니다. 다른 학원으로 바뀐 요청에는 이전 대화 상태를 적용하지 않습니다.

- 오답이 가장 많은 과제는 승인 과제 목록의 모든 행이 리포트 전체 문항 수와 정답 수에 맞을 때만 비교합니다. 다시 풀 자료의 재전송 가능 여부는 별도로 표시합니다. 대여 안내를 이어 묻는 경우에는 직전에 확인한 품목의 승인 반출 규정을 조회합니다.

대화 조건과 한 기간만 확인된 비교를 개선한 중간 실행은 공개 331/393이었습니다. 과목별 취약 영역과 과제별 오답 검증, 대여 반출 규정을 추가한 최종 결과는 335/393입니다. 합계로 검증할 수 없는 과제 목록에서 검색 상위 행만으로 최대 오답을 고르는 방식은 적용 대상에서 제외했습니다. [TEST_REPORT.md](TEST_REPORT.md)

## 후속 비교 · 적용일과 식별자 결합, 검색 점수 조정

- **기간 우선순위**를 적용해 승인된 임시 정류장·막차 변경·시설 운영 변경을 질문의 날짜로 조회합니다. 시설은 공지의 시작일과 종료일, 대상 시설, 요일이 모두 일치할 때 변경 시간을 사용합니다. 기간이 끝나면 확인된 정규 운영 시간을 사용하거나 보류합니다.
- **키를 확인한 행 결합**으로 학원 수업 종료 시각 이후의 하원 출발을 찾습니다. 같은 승인 운행표의 차량·하원 회차·정류장 행을 연결해 도착 시각을 답합니다. 막차는 정규표에서 마지막 회차를 확인하고 그 회차에 해당하는 변경 공지의 출발 시각을 인용합니다.

## 후속 채택 · 시험 이름과 평가 지표 연결

월말 평가 점수와 단어 시험 정답률을 학습 리포트의 개별 결과로 처리합니다. 먼저 서버 권한으로 원생을 확인하고, 승인된 분석 기간과 활성 개정판에 범위를 좁힙니다.

- 월말 평가는 요청 기간과 일치하는 평가명·점수 열을 함께 인용합니다. 과목이 지정되면 같은 과목만 사용합니다. 다른 평가 행이나 전체 정답률을 대신 쓰는 방식은 제외했습니다.
- 단어 시험은 승인된 단원 집계에 과제 하나가 직접 연결되고 그 과제명이 시험을 식별할 때 답합니다. 같은 달의 어휘 유형 집계는 문항 구성이 다를 수 있어 제외했습니다. 주차가 지정되면 같은 주차의 과제만 선택하고, 일치하는 시험이 여러 건이면 어느 시험인지 확인합니다.
- 월말 점수는 해당 월의 승인 학습 분석 근거와 읽을 수 있는 점수 표가 필요합니다. 단어 시험에 과제별 승인 연결이 없거나 재시험 결과·외부 학교 시험을 요청하면 승인 근거 부족으로 처리합니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 통학표의 정류장과 회차 연결

학교급이 명시된 회차 열을 정류장 행과 교차해 선택합니다. 질문이 회차를 직접 지정하면 그 번호를 사용하고, 회차가 빠지면 질문이나 권한 있는 원생의 등록 반에서 확인한 학교급을 사용합니다. 노선과 학교 출입구는 별도 조건입니다. 통학표의 열 순서가 달라도 헤더와 각 행에서 근거를 확인합니다.

정규 시각과 변경 시각은 학원 현지 날짜의 적용 기간으로 구분합니다. 동일 회차의 정규 출발 시각을 여러 노선에서 확인한 경우 값이 일치해야 합니다. 적용 중인 변경 행의 출발 시간이 명확하면 그 행을 인용합니다. 변경된 정류장 시각을 규정에 나온 지연 시간으로 추정하거나, 확인할 수 없는 날짜의 정규 시각을 대신 내는 방식은 제외했습니다.

승인 안내에 미운행이 명시돼 있으면 해당 문장만 인용합니다. 차량 자료가 비어 있거나 개별 픽업에 관한 근거가 부족하면 일반 출결 문서로 보충하지 않습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 결석 보강 규정과 확정 일정 분리

결석 전 연락 기한, 이미 발생한 질병 결석의 증빙, 원어민 스피킹의 대체 방식을 별도 항목으로 확인합니다. 예정된 질병 결석에는 같은 승인 규정에 있는 사전 연락 조건과 예외를 함께 안내합니다. 출결 처리만 설명하는 증빙 문장이나 학원 사정으로 휴강한 날의 보강 공지는 개인 결석 규정에 섞지 않습니다.

반이 지정되면 반 이름이나 문서 메타데이터와 일치하는 승인 규정을 우선합니다. 같은 반의 적용 규정이 충돌하면 보류합니다. 답변에 사용한 문장이 같은 개정판의 승인 사실과 일치하면 문단과 정형 사실을 함께 연결합니다.

실제 개인 보강 일정은 권한 있는 원생의 승인 일정에 결석일이 명시되어 있을 때만 답합니다. 다른 결석일과 연결된 보강, 학원 전체 보강 공지, 증빙 규정은 개인 일정의 근거가 될 수 없습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 질문이 요구한 항목과 승인 근거 연결

- 정규 수업 시작·종료 시각과 강의실은 등록 반의 동일 행에서 요청한 열만 확인합니다. `정규 수업` 열을 시간표로 인식하는 범위는 전용 항목 조회로 제한했습니다. 일반 수업 시간 질문은 기존 승인 시간표 사실을 계속 사용합니다.
- 운영 규정은 입실 가능 시점, 자습실 운영 시간, 이용료, 등록 전 진단 시간으로 나눕니다. 입실 허용 범위의 `전부터`와 도착 마감의 `전까지`를 구분하고 이용료 답변에는 적용 대상 조건을 포함합니다.
- 복합 길찾기는 주소와 지하철 출구를 각각 검증해 실제 행을 인용합니다. 학원 전체 휴강에는 전체 휴강이 승인된 공지만 사용하고, 반별 보강은 기존 일정 조회로 처리합니다.
- 원장의 학력은 해당 직책과 이름이 일치하는 행이나 인물 절에서만 확인합니다. 과거 리포트에 기록된 학습 지도를 요청하면 권한 있는 리포트에서 기록을 찾아 인용합니다.

중간 실행에서 지하철 출구 경로가 주소를 빠뜨렸고, 학원 전체 휴강 경로가 반별 보강 요청을 가로챘습니다. 모든 시간표 경로에 머리글을 확대하는 방식도 승인 사실 인용 한 건을 누락시켰습니다. 각 경로를 요청한 항목에 한정한 뒤 고정 회귀와 통합 테스트를 다시 실행했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 적용 조건과 실제 판정 위치

- 가족 동시 등록 할인은 유효한 승인 안내에서 적용 대상, 할인율, 제외 항목을 같은 절로 묶습니다. 가족 할인과 무관한 등록 행사 및 기본 수강료는 제외하고, 유효한 정책끼리 조건이 다르면 보류합니다.
- 행사일의 대체 수업은 승인 휴강과 보강 사실, 같은 공지의 행사 제목과 반·수업 종류·보강 시각이 일치하는 표 행을 확인합니다. 날짜가 가까운 정규 수업이나 다른 행사로 대체하지 않습니다.
- 감점 사유는 요청한 원생·기간·단원의 승인 채점 판정에서 조회합니다. 위치가 하나로 확인될 때 판정 문장을 인용 위치로 지정합니다. 감점 횟수만 적혀 있으면 사유를 추정하지 않습니다.
- 자습실 이용 자격은 요청 학교급에 대한 공식 규정과 담당자 답변을 비교합니다. 반 이동 시 수강료는 승인된 차액 정산 조항을 조회합니다.

중간 검증에서 한 줄로 정규화된 게시판의 날짜 뒤 본문이 작성자 표지에 포함돼 누락되는 문제를 확인했습니다. 표지 범위를 작성자와 날짜로 한정했습니다. 감점 사실 인용도 단원명만 일치한 과제 목록을 먼저 선택해, 실제 판정 내용이 있는 위치를 찾도록 바꿨습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 시간표 적용 기간과 휴원 공지의 날짜 연결

- 변경 시간표의 적용 종료일과 정규 복귀일은 해당 반 또는 학년·과정이 일치하는 행에서 확인합니다. 표마다 연도나 요일을 다르게 표기해도 실제 시작일과 종료일로 비교합니다.
- 연속 휴원 기간은 같은 승인 공지의 시작일·종료일 문구와 날짜별 승인 사실을 대조합니다. 보강을 함께 요청하면 같은 공지의 해당 반·휴강일에 연결된 행을 별도로 검증합니다. 보강 근거가 없으면 확인된 휴원 기간만 안내합니다.
- 공사나 시설 점검에 따른 휴강은 같은 시설·사유를 명시한 공지만 사용합니다. 학교 시험 범위는 학교·학년·과목이 일치하는 범위 열을 확인합니다. 카탈로그에 없는 선행 과정의 수강료와 요일은 보류합니다.

중간 검증에서 연도·요일을 포함한 적용 기간과 날짜만 적은 적용 기간을 문자열로 비교하면 같은 날짜도 충돌했습니다. 시작일·종료일을 날짜로 변환해 대조한 뒤 동일 문항을 다시 확인했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 주차별 준비물과 시간표의 요일별 시각

- 주차별 실험 계획은 날짜·상대 주·월을 달력 범위로 바꾸고, 승인 표에서 등록 반과 범위가 일치하는 행을 고릅니다. 실험 주제와 준비물 열을 각각 확인하며, 월 단위 준비물은 해당 반에서 값이 확인된 주차를 순서대로 인용합니다.
- 공개 수업 시각과 성적 통계를 한 번에 물으면 각각 검증합니다. 성적 통계가 확인되지 않아도 공개 시간표의 확인된 시각은 부분 답변에 남깁니다.
- 요일 격자는 반 또는 클리닉이 배치된 요일과 교시 셀의 해당 시간 범위를 연결합니다. 평일과 토요일 시각이 한 셀에 있어도 실제 배치 요일의 범위만 답하고, 시간 축과 선택 요일 열을 인용합니다.

중간 실행에서 숫자가 붙은 수업 주차를 주차장 문의로 분류하던 문제가 드러났습니다. 두 표현을 질문 해석 단계에서 분리하고, 기존 인용 순서를 유지하면서 답변에 사용한 시각 열을 추가했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 선납 수강월과 후속 선발 시험의 근거 확인

- 선납 문의에서 납부일과 수강월을 별도로 해석합니다. 해당 반의 수강월에 유효한 승인 수강료를 조회하고, 같은 승인 개정판에서 납부 시점에 따른 적용 규정을 확인합니다. 적용 규정이 없으면 확인된 기본 수강료만 부분 답변에 남깁니다.
- 다음 선발 시험을 묻는 후속 질문은 직전 학원 정보 질문의 과정만 이어받습니다. 같은 과정의 승인 공지에서 앞으로 열릴 시험의 날짜와 시각을 함께 확인합니다. 접수와 시험을 구분하고, 같은 시험일에 승인 시각이 충돌하면 보류합니다.
- 학교 시험 결석은 기말·중간 대비 기간과 해당 반에 적용되는 보강·대체 조항을 찾습니다. 와이파이 미운영은 요청한 이용 대상에 해당하는 승인 사실을 인용합니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 학습 상담 기간과 생성 인용 검증

학습 상담은 리포트 작성 월과 지도가 시행되는 월을 구분합니다. 요청 연도·월의 승인 기록이 없으면 다른 기간을 공급자에게 전달하지 않습니다. 시행 월에 대한 질문은 해당 월에 시행한다고 명시한 승인 지도 기록을 인용할 수 있습니다. 단순히 특정 월의 학습 방향을 다시 확인하는 질문은 그 월의 리포트에서 확인된 지도를 우선합니다.

생성 참고 의견에 등장하는 수치는 모델이 선택한 출처의 전송용 사실 텍스트에서 확인합니다. 사용하지 않은 문서의 숫자와 모델에 전달하지 않은 유효기간 값은 허용 목록에서 제외합니다. 화면에 출력하는 확정 기록의 인용은 모델의 인용 선택과 별도로 남깁니다. 외부 호출 횟수 제한과 승인 확인은 기존 방식대로 적용합니다. 생성 문장 전체의 의미 검증은 숫자와 출처의 일치 검사보다 넓은 과제로 남아 있습니다.

### OCR 분할 모드의 위치 합의 비교

공개 회귀의 스캔 원본 3개를 렌더링해 표와 문장 위치를 확인했습니다. 같은 기울기 보정 이미지에 적용한 자동 분할과 단일 블록 분할 결과에서 숫자 문자열, 단어 경계 상자, 신뢰도 75 기준을 대조했습니다. 스크립트와 출력은 로컬 `.git/rag-validation/ocr-position-consensus.cjs`와 `.git/rag-validation/ocr-position-consensus.jsonl`에 있습니다.

- 통학표 도착 시각은 같은 위치에서 신뢰도 96·95로 일치했습니다. 해당 열의 정류장 전체 이름은 한 모드에서만 정확히 읽혔습니다.
- 행사 시간 범위와 휴강 차감 금액은 두 모드의 구분 기호 판독이 달랐습니다. 상담 신청 기한의 일자는 같은 위치에서 읽혔지만 신뢰도가 47·72였습니다. 같은 숫자가 발행일에도 있어 페이지 단위 일치로는 구분할 수 없었습니다.

위치와 숫자가 일치해도 같은 행·열 또는 문장의 조건이 확인돼야 답할 수 있습니다. 두 분할 모드의 결과를 합치는 방식은 적용 대상에서 제외했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 인용 범위에 맞춘 OCR 검증

문장과 표 셀을 인용할 때 해당 인용 구간에서 발견된 불확실 수치만 검사합니다. 선택 구간이 기록되지 않은 경우에는 기존 인용 범위 전체를 검사합니다. 검수가 필요한 페이지는 선택한 구간의 수치를 불확실로 보고, 다른 승인 문서의 날짜나 금액에 같은 숫자가 있더라도 판독 근거로 쓰지 않습니다.

근거를 읽는 단계에서 불확실한 문장을 제거합니다. 먼저 선택한 자료가 OCR 때문에 필요한 값을 뒷받침하지 못하면, 날짜 형식만 맞는 낮은 순위 문서의 다른 행사로 이동하지 않습니다. 다른 항목의 승인 근거가 있으면 부분 답변으로 남길 수 있습니다.

### 스캔 이진화 비교

## 후속 채택 · 할인 주장 검증과 공지 중복 처리

- 게시글에서 본 할인율은 해당 반의 승인 요금표와 적용 시점이 맞는 승인 규정으로 따로 확인합니다. 명시된 할인율·반·청구 단위가 일치하고 별도 조건 없이 적용한다는 규정이 있을 때만 할인 금액을 계산합니다. 적용 여부가 충돌하거나 조건이 빠져 있으면 확인된 정가와 청구 단위만 안내합니다.
- 형제 할인율과 교재비 적용 여부는 같은 승인 규정의 두 근거로 검증합니다. 교재비 가격표와 다른 종류의 할인은 해당 질문의 인용에서 제외합니다. 교재비 적용 여부의 근거가 빠지면 할인율만 부분 답변에 남깁니다.
- 중복 검색 제외에는 본문 구조·학원·문서 종류·공개 범위·대상·적용 기간·OCR 판독 정보가 같아야 합니다. 검색 시 원본 최신판이 현재 요청에서 후보가 될 수 있고 본문이 여전히 같을 때만 사본을 제외합니다.

게시판 내부의 역할 표기와 같은 항목에 실린 악성 지시를 구분해도 작성자의 권한을 독립적으로 검증할 수는 없습니다. 게시판 글의 자체 표기만으로 할인 적용 여부를 확정하는 방식은 제외했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 전체 답변 줄과 실제 인용을 대조하는 평가

슬롯 v4는 슬롯마다 허용한 전체 답변 줄과 원본 근거를 대조합니다. 하나의 대체 근거 묶음에서 모든 필수 출처가 실제로 인용돼야 합니다. 여러 묶음에서 인용과 근거 문장을 따로 가져오면 해당 슬롯을 충족하지 못합니다. 표 근거는 선택한 열 목록도 비교합니다.

각 답변 줄은 입증된 사실 슬롯 또는 검수된 제목·안내 문구에 속해야 합니다. 다른 반의 금액을 덧붙이거나, 맞는 금액 뒤에 부정을 붙이거나, 질문과 무관한 행·열을 인용하면 실패합니다. 문자열 형식이 다른 유효한 표현은 검수자가 대체 답변 줄로 승인할 수 있습니다. 기존 슬롯 v2·v3 결과는 별도로 재현할 수 있습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 독립 평가 입력의 중복 점검

외부 평가를 시작할 때 학원 ID, 문항 ID, 정규화한 질문과 대화 이력, 원본 파일의 SHA-256, UTF-8 문서 본문을 저장소의 개발·공개·합성 자료와 대조합니다. 파일명을 바꾼 같은 PDF·DOCX·HWPX는 원본 해시로 찾고, 텍스트는 파일명이나 공백이 달라도 본문을 비교합니다.

자동 채점 결과와 입력 중복 상태를 분리합니다. 학원 ID·문항 ID·문서가 겹치면 `known_overlap`을 기록합니다. 동일한 질문은 새 학원에서도 나올 수 있으므로 별도 목록에 표시합니다. 파일을 새로 렌더링한 경우나 문구를 다시 쓴 경우는 이 비교만으로 검출할 수 없습니다. 출처와 문항 작성 과정을 사람이 검수해야 합니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 공지 본문의 행사 회차 검증

표가 없는 승인 공지에서도 개최를 명시한 문장을 근거로 사용합니다. 한 문장 안에서 행사명, 날짜, 장소, 시작 시각의 연결을 확인하고 그 문장을 원본 문단 위치와 함께 인용합니다. 같은 문단에 여러 회차가 있으면 요청한 날짜와 요일이 일치하는 문장만 선택합니다.

표와 문장에 적힌 `15:00`과 `오후 3시`는 같은 값으로 비교합니다. 오전·오후가 빠진 표현은 원문 그대로 구분합니다. 값이 충돌하면 해당 값을 포함한 전체 인용 후보를 제외합니다. 장소가 독립적인 표 셀로 확인되면 부분 답변을 제공합니다. 접수와 조건부 후보 문구는 개최 근거로 사용하지 않습니다. 명시된 승인 취소는 행사명과 날짜에 묶어 확인합니다.

초기 실험에서 개최 문장만 추출했을 때 같은 문단의 취소 안내를 놓쳤습니다. 승인된 취소 문장을 별도로 검사하도록 보완했습니다. 회차가 다른 취소나 승인 전 초안은 해당 회차의 근거를 막지 않습니다. 적용 범위는 날짜·장소·시각 역할이 명시된 개최 문장입니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 평가 공급자와 실제 요청 계측

평가 CLI가 기본 Mock과 두 Gemini 모드를 구분합니다. `gemini`는 운영 어댑터와 개인정보 전송 정책을 그대로 사용합니다. `gemini-synthetic`은 저장소의 기존 가상 학원 자료에서만 학습 조언의 생성 경로를 검증합니다. 외부 평가 폴더에는 이 합성 전용 모드를 허용하지 않습니다. 기존 Gemini 호환 HTTP 어댑터를 재사용했습니다. [Google Gemini API 공식 문서](https://ai.google.dev/gemini-api/docs/openai)

모든 문항을 같은 엔진과 채점기로 처리하고, 엔진이 생성이 필요하다고 판단한 경우에만 공급자를 호출합니다. 공급자 호출 수에는 이력 재생도 포함됩니다. HTTP 요청, 개인정보 정책에 따른 보류, 모의 장애 문항, 인증 실패와 실행 전체 요청 한도는 별도로 기록합니다. 실제 공급자를 켠 실행에서도 `api_state`의 장애는 로컬에서 재현합니다. 문항마다 모델 호출을 강제하는 비교는 비용과 운영 경로가 달라 별도 실험으로 분류합니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 승인 취약 영역에서 복습 방향 안내

외부 전송이 제한되거나 생성 공급자를 설정하지 않은 경우에도 같은 원생·기간·과목의 승인 취약 영역을 원문에서 확인해 복습 방향을 안내할 수 있습니다. 표는 단원과 진단이 같은 행에 있어야 하고, 문단은 같은 판정 항목에 연결되어야 합니다. 한 리포트에서 확인한 항목들을 제시하며, 여러 리포트의 판정이 충돌하거나 원문 위치가 확정되지 않으면 담당자에게 연결합니다.

기록된 관찰은 인용하고 복습 제안은 별도 문장으로 표시합니다. 강사 의견이나 구체적 학습 계획을 요청했는데 해당 근거가 없으면 누락 항목을 적은 부분 답변을 제공합니다. 강사가 기록한 내용을 확인하는 질문은 승인 지도 조회 경로를 사용합니다. 점수만 확인되는 경우에는 기존 담당자 연결 기준을 적용합니다.

진단 문장만 일치해도 출처를 찾는 초기 실험은 같은 문단의 다른 단원에 그 진단을 붙일 수 있었습니다. 표 머리글과 판정 항목을 함께 읽어 원문에서 일치하는 단원과 진단의 위치를 확인하도록 수정했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 분실·파손 비용의 물품과 조건 검증

재발급 비용 상담에서 물품, 분실·파손 조건, 결제 여부를 같은 문장 또는 표 행에서 확인합니다. 표는 물품·사유·비용의 열 위치를 사용합니다. 문장은 금액 바로 뒤의 납부 표현이나 금액 바로 앞의 비용 항목을 확인합니다. 무료 규정은 같은 물품과 조건에 명시된 경우에 안내합니다.

원화 단위와 숫자 구분을 확인하며 `5:000`과 `5: 000원` 같은 값을 보류합니다. OCR 신뢰도가 높아도 금액 자체의 형식과 원문의 조건을 따로 검사합니다. 같은 물품·조건에 승인 금액이 충돌하면 보류하고, 다른 물품이나 파손 행의 비용은 분실 비용에 합치지 않습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 비교 · 상담 날짜의 역할 검증과 PDF 렌더링

복합 상담 질문은 운영 기간, 신청 시작일, 신청 마감일을 별도 항목으로 확인합니다. 승인 공지의 같은 절이나 표의 같은 행에서 항목별 근거를 찾습니다. 같은 제목이 반복된 절은 출현 순서로 구분합니다. 같은 절에 여러 운영 회차가 있으면 회차가 명시되지 않은 신청일을 붙이지 않습니다. 한국어 날짜 범위에서 생략된 종료 월을 해석하고 요일을 달력과 대조합니다. 날짜 역할이 확인되지 않으면 확인한 항목과 원본 위치를 남기고 누락 항목을 표시합니다. 이 경로의 외부 생성 요청은 0건입니다.

| 방법                                   | 결정        | 관측 결과                                                                                                                         |

## 후속 채택 · 학습 조언에 필요한 진단과 지도 근거

계획 엔진에서 과목·단원·반을 지정한 학습 조언은 요청 범위의 승인 진단이나 지도 자료를 확인한 뒤 생성합니다. 단원 정답률은 점수 조회에 사용할 수 있습니다. 점수만 있고 진단과 지도 자료를 확인할 수 없으면 상담 담당자에게 연결합니다.

복합 과목 리포트는 같은 출처의 표에서 단원과 과목을 연결합니다. 다른 단원·반의 자료는 생성 입력에서 제외합니다. 취약 영역은 원문에서 단원과 관찰이 같은 위치에 연결된 경우에 전달합니다. 지도 문서는 범위 확인 후 최대 3개를 전달하며, 생성된 조언은 실제 사용한 진단 또는 지도 출처를 인용해야 합니다. 출처가 빠지면 담당자에게 연결합니다.

공급자가 응답 가능한지 사전에 확인하는 경로와 호출한 뒤에야 확인되는 타임아웃은 각각 검증했습니다. 타임아웃 문항의 입력 조건과 호출 예산은 유지했습니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 행사 시작과 종료 시각의 분리 검증

행사 표와 본문의 시간 범위를 한 표현으로 읽어 시작·종료 시각을 각각 검증합니다. 종료 토큰의 판독이 깨지거나 두 시각을 연결하는 범위 표기가 없으면 완전한 시간으로 사용하지 않습니다. 익일 표시 없이 종료가 시작보다 이른 범위도 보류합니다. 날짜는 행사 회차를 구분하는 데 쓸 수 있지만 같은 셀에 검증되지 않은 시각이 함께 있으면 그 셀 전체를 답변에 내보내지 않습니다.

시작만 적은 공지와 같은 시작의 범위 공지는 함께 검증할 수 있습니다. 종료가 충돌하면 종료가 담긴 근거는 제외합니다. 시작 시각을 묻고 별도 승인 공지에서 시작만 확인되는 경우에는 그 공지를 인용합니다. 시간 범위는 화면에 `~`로 표시하고, 인용·원문 검수에는 표와 본문의 원래 문자열을 전달합니다. [테스트 보고서](TEST_REPORT.md)

## 후속 채택 · 독립 평가의 사전 검수와 출처 권한 검사

기존 자동 점수와 독립 판정을 별도 필드에 기록합니다. 독립 판정은 3개 학원·300문항 이상, 슬롯 v4 정답률 95% 이상, 권한·승인 위반 0건을 요구합니다. 공개 자료의 재사용 여부를 확인하고, 검수 기록이 같은 원본·정답·평가 코드 해시와 전체 문항 ID를 가리키는지 검사합니다. 일반 상담에서 Mock이 답변을 생성했다면 독립 판정을 보류합니다.

사전 점검은 답변 가능한 문항의 필수 사실과 인용 위치, 부분 답변의 누락 항목, 확인 질문의 선택지, 근거 문서의 승인·접근 범위를 검사합니다. 실행 중 원본·정답·검수 기록·코드가 바뀌면 결과 확정을 중단합니다. 평가 안전 검사는 학생·학원 외에 반 전용 자료와 교직원 전용 자료의 검색·모델 입력·인용도 확인합니다. [실행과 판정 기준](TEST_REPORT.md)

| 공개 보류 상태를 반영한 슬롯 채점                    | 채택        | 기존 v4 결과를 보존하고 v4.1에서 담당자 연결 상태와 사유를 검사합니다. 사실·출처·행·열 검사는 같습니다.                                                        |

검색과 생성 설정은 동일한 상태에서 비교했습니다. 등록·적용 기간과 복합 질문에서 관측된 개선은 근거 선택과 요청 분해에서 나왔습니다. 스캔 결과는 단순한 확대나 언어 제한으로 일관되게 개선되지 않았습니다. 스캔의 장소·시간을 비교한 원문과 출력은 로컬 평가 폴더의 `ocr-scale-ablation.json`과 `ocr-kor-only.json`에 있습니다. [테스트 보고서](TEST_REPORT.md)
