# 학원 위치와 주차 안내

## 학원 위치

학원 주소는 가상시 온답구 배움로 12, 온답빌딩 3층입니다. 학원 입구는 건물 정문으로 들어와 엘리베이터에서 내리면 오른쪽입니다.

## 주차

학부모 상담 방문 시 온답빌딩 지하 1층 주차장을 이용할 수 있습니다. 주차 요금은 처음 30분 무료이며 이후 10분당 500원입니다. 데스크에서 차량 번호를 등록해 주세요.
