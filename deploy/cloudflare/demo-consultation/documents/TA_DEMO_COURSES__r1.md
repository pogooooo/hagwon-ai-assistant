# 학년별 수학 수업 안내

## 개설 수업

초등학생은 초등 수학반에서, 중학생은 중2 내신반과 중3반에서 수학을 배웁니다. 고등학생은 고1반에서 수학을 배웁니다.

## 교육 대상 및 개설 과목

| 구분 | 대상    | 개설 반     |
| ---- | ------- | ----------- |
| 수학 | 초1~초6 | 초등 수학반 |
| 수학 | 중2     | 중2 내신반  |
| 수학 | 중3     | 중3반       |
| 수학 | 고1     | 고1반       |
